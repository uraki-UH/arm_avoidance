# CI進捗メモの読み取り

固定仕様 `policy.md` に従い、入力メモの実施状況をJSONへ変換するための手順。

まず入力全体を読み、作業の流れを把握すること。各段落が実施済みの報告、実行中の報告、将来の予定、補足資料のいずれに当たるかを整理すること。対象外の話題も含めて全体の構造を確認し、どの記述が対象の状態判断に使えるかを見極めること。この整理は回答本文へ出さないこと。

次に lint、build、test をそれぞれ個別に点検すること。対象の表記揺れも拾い、関係する記述を候補として整理すること。候補ごとに実行したか、終了したか、成否が記載されているか、日時は何か、所要時間と件数が記載されているかを確認すること。候補が複数あるときは、それぞれの関係を整理して最新試行を確定すること。

選択した試行の値を、固定仕様の各フィールドへ対応付けること。時間の単位を確認し、必要な場合はミリ秒へ換算すること。値が見当たらない場合は、対象試行の記述をもう一度点検し、それでもなければ `null` とすること。予定や以前の試行の数値を混ぜないよう、対応付けを項目ごとに確認すること。

出力前に入力全体へ戻り、最初に拾った結果より新しい報告がないか、実測と予測を取り違えていないかを確認すること。さらに各フィールドの型、必要なキーの有無、追加キーの有無を固定仕様と照合すること。最後にJSONの構文を確認し、単一のJSONオブジェクトのみを出力すること。
