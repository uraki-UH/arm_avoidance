# 指示書の品質・使用量改善

既定は追加外部送信のない運用。[共通改善手順](../delegate-agent-work/references/improvement-loop.md)を使用。

1. 既存の通常作業記録をローカルで集計。取得可能なusage・品質・時間と欠測を区別。
2. 非公開の生ログ・コード・入力・正解・スキル本文は別AIへ渡さない。会話へ返す集計もパスやエラー本文を含めず、共有可能な値だけ。
3. 共有可能な集計から改善候補を検討。原本への適用は依頼範囲に従う。
4. 次の許可済み通常作業で品質と使用量を観測。条件差があれば参考比較。品質低下した候補は不採用。欠測をゼロ扱いしない。

## 個別に許可された外部比較

同梱`skill_optimizer/`はCodex CLIへ指示・入力を送信する実装。共有可能なペイロード・宛先・用途をユーザーが明示許可した場合だけ使用。単なるテストや改善依頼を送信許可と解釈しない。CLIの`--allow-cloud-evaluation`は実行ガードの解除であり、許可取得の代替ではない。

実装仕様は[実行ガイド](skill_optimizer/README.md)を参照。固定仕様・正解・評価器は変更対象外。train / validation / testを分離し、同モデル・同条件で品質とusageを比較。探索分も総コストへ含め、原本と候補を分離。テキスト比較の結果を、実ファイル編集・ROS・スキル自動発見の効果へ一般化しない。
