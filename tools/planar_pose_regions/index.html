評価方法・対象範囲

対象：全3～5関節、設定した可動域。±150°・±180°も選択可能。占有適応の制約：min_dev ≤ A(q−q0) ≤ max_dev。関節角・累積角の一次制約と元の可動域の共通部分がノード領域。二次制約は未実装。

占有：全許容姿勢の保守的包絡。灰：共通 / 橙：選択側だけ / 緑：隣接側だけ。64方向の支持半平面に、相対関節角による到達距離・連動支持の上界を反映。リンク別の凸包化による過大近似あり。共通率：共通セル / 和集合セル。包絡と代表姿勢を別表示。セル中心基準であり、衝突安全保証ではない。

分割：全候補包絡、または局所掃引モデルによる候補絞り込み。モデル係数：リンク回転・下流並進の閉形式。上位2方向を包絡で比較し、一次端点誤差が大きい場合は最広角の方向も追加。境界候補の順位付け：各リンク24輪郭点の法線とヤコビアン。採用後の包絡・領域被覆は従来方式と共通。基底Aの自由探索・二次制約は対象外。

折りたたみ：隣接リンクの到達距離80%の境界による近位2関節の初期層別。全関節の直積分割なし。通常分割には相対関節角の上位1候補も追加。分割優先度には代表姿勢の占有セル数・姿勢サイズを反映。固定ノード予算では他の領域が粗くなる場合あり。

同一設定・同一姿勢の占有登録は比較2方式で共有。構築時間は描画待ちを含む合計であり、共有キャッシュを使う各方式の独立性能比較ではない。再生中は現在姿勢のみ評価し、フレームごとの履歴蓄積はなし。

局所移動：現在姿勢→共有境界→隣接領域への進入。進入距離の上界：セル幅の半分。代表姿勢間の方式も選択可能。候補比較：開始姿勢からの追加掃引セル数／最大関節累積移動角。非劣候補から優先度に従って選択。軌道評価は有限サンプルであり、連続衝突保証・目標までの経路計画は対象外。軌道占有は別表示。

円形ツール：最終関節による円中心の回転。占有不変でも角度・ツール方向の保持。本デモ：独自の領域分割・到達集合の比較試作。既存GNG学習の変更、自己衝突、実機制御、安全認証：対象外。障害物例の評価：下記の到達集合比較のみ。

接続：全関節制約の共有面と通過姿勢。手先領域：全関節領域の順運動学による像。JSON：位置3成分・xyzw四元数・局所6成分ヤコビアン・XY位置支持上界・未折返しyaw区間。平面版の有効成分：x・y・yaw、真の6次元領域ではない形式。ヤコビアン：基準姿勢近傍のみ、全領域の線形近似保証なし。位置と向きの周辺包絡の直積：正確な到達領域ではない外側近似。

手先位置で配置：代表姿勢のXY位置、短線による向き、代表→共有通過姿勢→代表の曲線。曲線の描画：有限サンプル。関節共有面による位置・向きの連続接続。手先領域の重なりによる辺追加なし。速度・加速度の連続接続：未保証。選択周辺：2辺以内。接続関係の全体配置：距離尺度なし。2軸投影：外接枠、断面：他関節固定の多角形。

到達集合比較：現在姿勢からの手動照会。初速：全関節への同じ入力値。中心加速度：指定値、または選択隣接領域への進入姿勢からの逆算。加速度幅：各関節の独立パラメータ、時間変数：全関節共有。「軌道族全体」と「中心軌道への絞り込み」の各比較内で、開始姿勢・速度・軌道族・時間区間の共通化。中心軌道の停止姿勢と手先軌道の表示。保存：開始／中心軌道終端の手先姿勢、6成分差分、占有包絡・制約判定の比較用JSON。

ARMTD型：ARMTD論文の「事前の関節到達集合→初速度のslice→現在角への回転→リンク占有」に沿った独立計算核。事前初速区間：10 deg/s幅のビン、保持キャッシュ：直近1設定。軌道：定加速度の計画区間＋停止までの制動区間。表現：時間・加速度の共有依存多項式、3次Taylorと4次残差。次数・項数の削減分：独立残差への移行、slice後も保持。大角度変動：sin・cosの全区間への退避。原著のCORA・rotatotope・GPU・IPOPTの完全再現ではないCPU向け検証実装。

比較方式：関節区間包絡／ARMTD型の関節回転合成／平面特化の累積角。各時間区間の64方向支持上界を合併し、各方式の格子登録は1回。既存ノード構築とは別の制動付き軌道評価、既存方式への自動置換なし。照会時間：事前処理を含む本ブラウザの単発値。2方式目以降での事前計算共有のため、独立した冷間性能比較ではない値。

組み込み口：armtd_reachability.create_backend(planar_pose)のcompare・evaluate・evaluate_graph_edge。隣接接続の評価：開始／目標の領域所属、二次軌道と一次制約の全境界交点、関節角・速度・計画加速度・制動加速度、静的障害物との支持分離。分離未確認：衝突確定とは別。自己衝突・追従誤差・トルク制約・移動障害物・全体経路最適化：対象外。浮動小数点の誤差余裕：検証付き丸め演算による証明ではない実装。実機への送信・安全保証：なし。
