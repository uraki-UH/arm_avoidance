# 基数ソートの複数シード検証

[本番相当の単一シード比較](../gng_radix_production_20260924/README.md)に対する追加検証。同一シードのグラフ完全一致ではなく、シード間の品質のばらつきと方式間の差を比較。

## 条件

- 交差点bagの同じ先頭200フレーム、最初の50フレームを平均から除外。入力約16万点、学習4,000回、上限2万ノード、`node.grid=0.5`。
- 入力voxel幅0.1／0.5 m、Boost／32bit安定基数ソート、6シード（11、101、1009、10007、104729、20260924）。シードごとに実行順を交互に切替。
- Release＋LTO、CPU 0固定。比較用コピーのみ、フレームの学習乱数を`seed + frame_number`、LPF時間刻みを0.1秒に固定。全点照合のシャッフルは従来のフレーム番号シードを維持。
- 観測支持を有効化し、原点(0,0,0)・画素表なしの実測レイ経路を評価。共分散・重み付き重点入力等の追加有効化なし。
- 点群転送＋GNG＋出力取得を計時。入力読込、ハッシュ、品質評価、観測範囲取得、スナップショット保存は計時外。
- ウォームアップ後、10フレームごとと最終フレームの計16フレームで被覆率・最近傍距離・観測角度範囲を評価。評価時だけ非有限値・原点・YAML範囲外を除外。学習入力へのフィルタ追加なし。
- 各シードの時間平均／品質平均を標本として、平均、標本標準偏差、方式の対応差、対応差の95% t区間（自由度5）を記録。相関するフレームを独立標本として数える処理なし。非有意だけを同等性の証明とする判定なし。
- 別途、各方式・各voxel幅で観測OFF／セル末尾代表点を30フレーム実行。同じシードの観測ON・セル先頭代表点とのグラフ一致を検査。初回フレームのBoost／radix実測代表点の距離・角度差も記録。

## 実行

既存の`gng_cpu_container`内:

```bash
bash /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/build.sh
bash /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/run.sh
python3 /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/summarize.py
```

生ログ・フレームJSON・NPZ・共有ライブラリは`artifacts/gng_radix_multiseed_20260924/`。ビルドは`/tmp/gng_radix_multiseed_build/`。比較用コピーは`ais_gng_cpu/experimental/gng_radix_trials/`。追加のシード指定・代表点切替APIはこのコピーに限定。

## 結果と判断

6シード各200フレーム、全体平均は観測支持ON。基数ソート採用前後の比較:

| voxel幅 | 全体時間 Boost → radix | 短縮率 | 0.2 m被覆率 Boost → radix | 被覆率の平均差 | Boostのシード間標準偏差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0.1 m | 108.239 → 101.569 ms | 6.16% | 77.3682 → 77.4576% | +0.0894ポイント | 0.1387ポイント |
| 0.5 m | 39.828 → 35.947 ms | 9.74% | 60.1714 → 60.1126% | −0.0588ポイント | 0.1540ポイント |

平均最近傍距離の方式差は−0.248／+0.154 mm、p95距離の差は−0.259／+0.295 mm。ノード数の差は平均+0.56／+2.24個。最終フレームの平均エッジ長差は−0.184／−0.266 mm。被覆、距離、ノード数、エッジ長の平均差は、それぞれBoost版のシード間標準偏差より小さい。

0.2 m被覆率の対応差の探索的95%区間は、0.1 mで[−0.170, +0.349]ポイント、0.5 mで[−0.301, +0.183]ポイント。6試行・単一bagの評価であり、全環境の同等性を証明する検定ではない。今回の入力で明確な品質悪化を認めず、点選択の分布を保つソート置換として本番CPU版へ採用。

ソート単体は8.656→2.307 ms／6.666→2.859 ms。全体で短縮した6.670／3.881 msの大部分がソートの短縮分。比較時間にはグラフ変化による後段処理量の差も含む。

## 観測代表点の切り分け

観測OFFまたは同じセルの末尾点を代表点に変更しても、全240対照フレームのグラフ・接続・クラスタ・入力ラベル・学習回数が一致。代表点変更時には比較した12観測出力すべてが変化。観測値の変更と学習グラフの変更は別経路。

初回フレームの実際のBoost／radix代表点の角度差は、0.1 mで平均0.0271°・p95 0.1971°・最大0.7981°、0.5 mで平均0.2126°・p95 0.7664°・最大3.5841°。全差は同一セル内の実測点間で発生。角度差は量子化誤差だけでも乱数だけでもなく、セル先頭の代表点変更によるもの。入力順を保持するradixでは元番号最小の点が代表点となり、観測出力の完全一致は保証しない。

観測の支持ノード率・平均yaw幅・平均pitch幅の方式差は、それぞれのシード間標準偏差内。意味は既存の「選択された実測点の観測範囲」のまま。全voxel点の観測範囲や不可視領域の証明ではない。

## 不変条件と保存物

- 2,400組の方式比較で全元点のセル対応、保持点数、セル数、整列セル列、セル区間が一致。全5,040フレームで4,000回学習。
- 既定シードの各方式各幅200フレーム、計800フレームが前回保存したグラフ等と一致。新しい検証APIや観測ONによるグラフ変更なし。
- 比較版のReleaseテスト34件、本番版17件が成功。画素参照・圧縮索引・レイへの復帰経路は既存観測APIテストで検証。実bagの観測量比較はレイ経路のみ。
- 本番にはソート・作業バッファ・テストを追加。検証用のシード固定、時刻固定、学習点保存、代表点切替、計測APIの追加なし。公開APIとYAML変更なし。入力上限20万点で作業バッファ約1.6 MB。
- 実時間・非固定乱数のインストール済みライブラリで、観測・重点入力・統計・イベント・差分有効の30フレームが成功。
