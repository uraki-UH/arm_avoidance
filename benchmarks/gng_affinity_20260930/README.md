## 条件・検証

- 環境: i7-14650HX、P論理CPU0–15／E16–23、Docker `gng_cpu_container`、ROS Humble。
- CPU設定: `powersave`、`no_turbo=1`、上限P2.2GHz／E1.6GHz、Docker CPU quotaなし。ホスト設定変更なし。
- 検出: `cpu_core/cpus`・`cpu_atom/cpus`。不明・許可Pなしは警告と非適用。コア番号固定なし。
- 入力: 既存交差点bag、`/lidar_points`。bag・TF・Viewer継続、入力開始位置は試行間で異なる。
- 試行: 各120秒×2条件×2回。無効→有効→有効→無効。初期149フレームを集計対象外。
- 停止境界: 最初のSIGINT通知より後のGNGログを各1フレーム除外。元集計も保存。
- 元集計: 無効2092件／平均42.362／最大54.06ms、有効2091件／42.462／56.64ms。
- 比較対象: 両条件とも撤去前の試作。無効は`enable_gng_cpu_affinity:=false`、有効は追加引数なし。
- 待機方式: 通常のOMP設定、PASSIVEへの変更なし。前回の単一Pコア固定＋PASSIVEとは異なる条件。
- 計測版: 前回の独立`libgng_cpu.so`を試験子プロセスの`LD_LIBRARY_PATH`だけで使用。
- 画面GNG: affinity適用／復元・stdout捕捉・診断CSV出力を含む時間。本体CSVだけでの比較なし。
- 画面−本体の平均: 無効0.09939ms／有効0.12095ms。差0.02156ms、affinity単体への分解なし。
- 負荷平均: 無効159930.06点／17674.60voxel／18968.28node、有効159931.37点／17717.48voxel／18987.86node。
- CPU確認: 有効条件はwarmupを含む21501段階行の全開始・終了点でPコア。区間内の完全な移動履歴ではない。
- 復帰確認: 有効steadyサンプルで元mask0–23を1095回観測。/procの100ms採取、毎フレーム全時刻の証明ではない。
- 単体: 8/8件成功。範囲解析・許可交差・既存worker維持・明示／例外復帰・マスク拡張防止。
- ビルド: Docker Release 1パッケージ成功。初回CTestはROS環境未読込のimport失敗、source後は成功。
- 通常起動: 診断ライブラリなし30秒、294入力、P群選択ログ・通常libロード確認成功。
- バッチ: 4/4試行成功、予測492秒／実482.61秒。
- 終了: 比較4回・通常起動1回・probeの所有24PID残留なし。既存bag・TF・Viewer・3コンテナ維持。
