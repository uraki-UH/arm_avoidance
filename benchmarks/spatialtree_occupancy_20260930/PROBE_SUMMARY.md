# 占有埋め込みの有限スモーク試験

- 対象: ホームの SpatialTree occupancy ブランチ。commit とコンパイラは metadata.json。
- 目的: 実行可能性、RMS 被覆と最大点変位の差、学習後代表点の剛体性の確認。
- 限界: 2 条件 × 1 試行。速度比較・最終収束性能の評価には不足。固定 7 関節の Panda 風モデル、23 代表点、69 次元。URDF 実機モデルではない。
- 条件: δ = 0.08 m、上限 1,000 ノード、50,000 学習反復。規則比較のテスト標本は 20,000 個。学習 seed = 7、テスト seed = 99。runner の seed はプログラム引数に未使用。
- コンパイル: C++17、-O3、-march=native。元 CMake の -ffast-math は不使用。
- 結果: R1/R2/R3 被覆率 91.42% / 87.57% / 86.11%。移動回数/反復 10.747 / 2.775 / 2.924。
- 辺評価: R2 の 4,313 辺。埋め込み RMS 中央値 0.0743 m、最大点変位中央値 0.1467 m、最大 0.3830 m。最大点変位 > δ の辺は 87.97%。各辺端点の代表点変位のみの測定であり、関節補間途中の掃引体積検証ではない。
- 剛体性: link_idx = 2 の第 1・第 3 代表点間隔。本来 0.210666686 m、20,000 個の FK 標本の最大誤差 0.000000075 m。R2 学習後 1,000 ノードでは中央値 0.189111233 m、最小 0.165116936 m、最大 0.202060565 m。全ノードが 0.1 mm の許容差を超過。この座標重心を実関節姿勢の FK と見なすことは不可。
- 実行時間: rules 2.115 秒、edges 0.516 秒、batch 全体 2.633 秒。初回予測は不明、初回後の残り予測 2.115 秒に対して実際の次試験は 0.516 秒。
- 実行: commands.txt。rigidity_probe は実際には Python subprocess の timeout = 15 秒で実行。commands.txt の timeout コマンドは再現用の等価手順。
- 終了: runner 2 試行は exit 0 / cleanup_ok。追加 probe も exit 0。cleanup.json で自分の試験 PID 残存なし、既存コンテナ ID 一致。既存プロセスの停止なし。
