## 圧縮の対象

固定7自由度腕をFKし、7リンク各3点とグリッパ2点の位置を連結。内部表現は23点×3座標＝69次元。
各点の重みはリンク表面積から設定、重みの和は1。距離は `sqrt(sum(w_k * |p_k(q1)-p_k(q2)|²))` [m]。
代表点の位置変化が小さい姿勢を同じ代表で受理する方式。占有ボクセル集合の厳密な一致判定や体積差の計算は未実装。

| 表示名 | rule引数 | 処理 |
| --- | ---: | --- |
| R1 | 0 | 通常のGNG更新・周期成長 |
| R2 | 1 | 許容距離から外れた入力だけ位置更新 |
| R3 | 2 | 範囲外入力に対する勝者の移動量制限 |
| R4 | 3 | 範囲外の実サンプルを新ノードへ追加 |
| R5 | 4 | R4と受理入力による重心更新 |

R2/R3の周期成長は、はみ出し率の移動平均と成長判定値による制御。
Python `metric_volume.py` の表面法線計量・必要ノード数概算は別実験で、C++のGNGには未接続。

## 実測で確認した制限

δ8 cm、上限1,000ノード、5万反復、固定7関節モデルの単発試験。実URDFでの性能・圧縮率の評価ではない。

- 更新回数: R1 10.747回/反復、R2 2.775回/反復、R3 2.924回/反復。
- 被覆率: 乱数テスト2万姿勢で91.42%／87.57%／86.11%。全可動域や過去全サンプルの被覆保証なし。
- 辺端点: R2の4,313辺でRMS中央値7.43 cm、代表点最大変位の中央値14.67 cm、全辺の最大38.30 cm。平均変位の閾値は各部位の最大変位上限ではない。
- 剛体性: 同一リンクの固定点間隔21.0667 cmが学習後中央値18.9111 cmへ変化。1,000ノード全件で0.1 mmの誤差超過。対照の2万FK標本では最大誤差7.5e-8 m。
- 解釈: 埋め込み座標の平均・線形移動で生じた代表点配置は、そのまま実アームのFK結果として利用不可。
- 辺の評価範囲: 端点間の点変位と `V+A*d` の一次体積見積り。実関節補間・掃引体積・辺の衝突検査は対象外。

## URDF学習への統合案（未実装）

1. 固定Panda風モデルの特徴生成を、実URDFの各リンク代表点・FKへ置換。
2. 実サンプルを代表にするR4を基に、ノードに元の関節角とFK特徴をセットで保持。現R4は上限到達時に追加失敗から線形移動へ進むため、容量不足を明示して実姿勢を保持する挙動へ変更。
3. 集約元の姿勢ID・関節接続情報を保持。占有の近さに加え、必要な手先姿勢・関節可動性の条件で代表を区別。平均された特徴から直接関節指令を生成しない設計。
4. 既存trainerの自己衝突検査・関節補間辺の検査・実形状VLUT生成を維持。圧縮グループの共通VLUTを使う場合は、所属姿勢全体の占有を含むことの検証が別途必要。

現行trainerのVLUT生成は `node.weight_angle` をFKして元URDF形状を配置する処理。
入力関節角を保持しない現在の実験ノードとは接続条件が異なる。
実URDFでのノード数、到達域・姿勢の被覆、元経路の維持、VLUT量、学習全体時間が次の比較対象。
前回の7/14次元検索速度は関節角距離の別測定であり、今回の69次元特徴にそのまま適用する根拠なし。
