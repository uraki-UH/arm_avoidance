# 境界ノード周辺の重点学習

CPUバックエンド専用。`graspnet.yaml`では有効、ノードのパラメータ既定値は無効。
点群の位置や総学習回数は変更せず、入力済み実測点が学習に選ばれる確率を変更。

## 起動時設定

| YAMLキー | graspnet.yamlの値 | 内容 |
| --- | --- | --- |
| `enable_boundary_attention` | true | 境界重点学習の有効化 |
| `boundary_attention.radius` | 0.03 | 境界からの対象半径[m] |
| `boundary_attention.ratio` | 0.2 | 総学習回数中の境界重点配分 |
| `boundary_attention.timeout_sec` | 0.5 | 境界キャッシュの有効期間[s] |

追加launch引数は不要。CPUライブラリ・ROSノードのビルド後にGNGを再起動して反映。
無効化はYAMLの`enable_boundary_attention: false`。パラメータの実行中変更は不可。
把持重点と境界重点が両方有効の場合、配分率の合計が1未満であることを起動時に確認。

## 境界と距離重み

- 前フレームのGNGで隣接数が`boundary.max_neighbors`以内のノードを使用。重点有効時は`boundary.enable_candidates`がfalseでも境界候補計算を実施。
- 幾何学的な物体境界の確定情報ではなく、既存の低次数ノード判定。遮蔽等の`boundary_evidence`による選別はなし。
- 有限座標の境界ノードだけで平衡kd-treeを構築し、入力実測点からの最近傍距離を検索。
- 最近傍距離をd、対象半径をrとして、d≤rの点に`exp(-4.5×d²/r²)`を付与。標準偏差r/3のガウス重み、半径外は0。
- 半径0.03 mでは境界上1、1 cmで約0.607、2 cmで約0.135、3 cmで約0.011。境界ノードの重複による加算なし。
- 初回、境界なし、対象点なし、古い時刻、同一入力時刻の再処理、時刻逆行、frame変更、受信停止時は境界枠を通常学習へ返却。
- 同一frame内の前回境界を利用。frame変更時のTF変換や、物体運動の予測はなし。単一入力点群のみ。

## 把持重点との併用

既存の[把持候補AABB重点](grasp_attention.md)を維持。
各重点集合を正規化して配分率で重み付けし、同一入力点の重みを加算して一つの重点抽選分布へ統合。

両集合に有効な点がある場合の初期配分は、把持重点0.5＋境界重点0.2＋通常方式0.3。
総学習回数5000なら重点合計約3500回、通常方式約1500回。重点内の把持／境界の内訳は確率的な配分で、毎回の厳密な個数固定ではない。
通常方式は既存の全体・unknown等の混合を保持し、完全な全点一様抽選という意味ではない。

把持候補が失効しても有効な境界点があれば境界重点を継続。境界だけが失効した場合は把持重点を継続。
GNG内部の既存入力範囲フィルタを適用し、除外点を重点指定で復活させない。フィルタ後は残存する重点重みで再正規化し、全部除外された場合は通常方式へ復帰。

重点分は既存の把持重点と同様、共分散・支持統計・観測方向件数・統計用勝者イベントへ計上しない。
重点枠を増やした分だけ通常方式の統計更新機会は減少。

## API・配信

`gng_set_weighted_priority_input(point_ids, weights, num_points, ratio)`を追加。
元点添字は重複なし、重みは有限な正値。入力順を維持して内部コピー。
不正値では設定を解除して失敗返却。次の点群入力、または1回のGNG実行終了で失効。
従来の一様重点API`gng_set_priority_input`も維持。

境界用ROSノード・トピック・メッセージの追加なし。`/downsampling/grasp`は引き続き把持AABBの選択点のみであり、境界重点点の表示ではない。

## 検証・制限

[ビルド・単体テスト・測定結果](../../gng_vlut_system/docs/releases/2026-09-16_boundary_attention.md)を参照。
境界付近の学習を増やす機能であり、未観測形状の復元や平面クラスタの過剰統合解消の保証はなし。
ノイズ・孤立ノードも境界候補になり得る。実点群での分割品質・全体フレーム時間は未検証。
