# CPU GNGのボクセル重点学習（撤去済み・過去仕様）

2026-09-25確認：追加コストと品質比較を踏まえ、ユーザー指示により本機能全体を撤去。
以下は評価当時の仕様であり、現在の設定・APIとしては使用不可。
移行方法と削除範囲は[リリースノート](../../gng_vlut_system/docs/releases/2026-09-25_nonplane_attention.md)を参照。

## スコアと抽選範囲

`enable_nonplane_attention: true`、`nonplane_attention.mode: voxel`で有効。
入力ボクセルの既存索引・元点対応を共用し、セルのスコアに比例してセルを抽選、そのセル内の元点を一様抽選。
セル点数を重みに乗算しないため、同じ群・同じスコアなら3点のセルと30点のセルの選択確率は同じ。
スコアは確率そのものではなく、群ごとに正規化する非負重み。学習器で獲得するスコアではない。
履歴照合は既存の整列済みセル番号の線形走査。セル索引・履歴のハッシュ要素を毎回確保する処理なし。
群ごとの重み部分和を一度構築し、学習抽選と出力抽選の初期集計へ共用。

セル幅は`input.voxel_grid_unit`と共通。`at128.yaml`は0.5 m、範囲は入力フィルタのX/Y ±200 m、Z ±20 m。
対象ノード周囲への半径拡張なし。`nonplane_attention.radius`は`mode: radius`だけで使用。
現在の入力支持点数が`min_support_points`を満たすセルへ、次の最大値をスコアとして設定。

| 根拠 | セルの重み |
| --- | --- |
| 非平面成分 | 直前結果の対象ノードを含むセルに`nonplane_weight`。成分ノード数は`min_component_nodes`で選別 |
| 新規占有 | 前回の占有表にないセルに`new_weight` |
| 表現不足 | `uncovered_weight × clamp(d² / (セル幅 × coverage_scale)², 0, 1)` |
| 履歴 | 前回セルスコア × `history_decay`。現在占有のないセルの履歴は破棄 |

`d²`は既存の全セル照合で得た代表点と最近傍ノードの距離二乗。同フレームで追加済みのノードも照合対象。
最近傍探索の追加実行なし。点が入った初回から新規占有・表現不足を重点化でき、非平面分類の確定待ちなし。
単独・小非平面成分に非平面スコアは付けないが、現在入力の新規占有・表現不足で選ばれる可能性はある。
安定した非平面成分の専用抑制や動静分類は未実装。履歴減衰だけでは静止した非平面を識別しない。

総学習回数は変更せず、`ratio`を重点枠へ配分。`at128.yaml`は4,000回中2,000回。
重点セルを「まとまった非平面ノードを含むセル群」と「それ以外の新規占有・表現不足等のセル群」へ分離。
両群に候補がある場合、前者の確率総量を`component_ratio`、後者を`1 - component_ratio`へ正規化。
各群の中ではスコア比例。背景のセル数が増えても非平面群の確率総量は変わらない。
既定0.8では重点2,000回中、非平面約1,600回・探索約400回の期待値。残り2,000回は全体学習。
片方の群が空なら、存在する群へ重点枠を返却。初回や履歴失効時は非平面群がなく、探索群だけの重点化。
履歴に保存する値は群別正規化前のスコア。`nonplane_weight: 0`の場合は非平面群への配分なし。
残余は全体学習。把持・境界重点との併用は合計比率1未満が必要。候補ゼロなら重点枠を全体へ返却。
重点枠は元点を使用するが、同じ観測の再学習を共分散・観測支持・統計用勝者イベントへ重複加算しない。
ノード即時追加は既存の全セル照合を継続使用。専用の予約枠や追加上限の突破はなく、ノード枠不足時の追従を保証しない。

通常のGNGエイジングは継続。オクルージョン判定による追加削除は2026-09-25のユーザー指示で撤去。
専用の方向索引・履歴・センサー原点取得・関連パラメータも削除済み。[判断記録](../../gng_vlut_system/docs/reject.md)。

## 設定と座標条件

全設定は起動時反映。ノード既定は機能OFF、`at128.yaml`では重点学習ON。

| `nonplane_attention.*` | at128値 | 用途・単位 |
| --- | --- | --- |
| `min_support_points` | 3 | 重点セルの入力支持点数 |
| `min_component_nodes` | 5 | 非平面重点成分のノード数 |
| `nonplane_weight` / `uncovered_weight` / `new_weight` | 1 / 1 / 0.5 | 非平面・表現不足・新規占有の重み |
| `history_decay` / `coverage_scale` | 0.5 / 0.5 | スコア保持率・セル幅に対する残差尺度 |
| `ratio` / `timeout_sec` | 0.5 / 0.5 | 重点学習比率・前回結果の有効時間[秒] |
| `component_ratio` | 0.8 | 重点枠内の非平面成分セル群への確率配分 |
| `enable_debug_points` / `max_debug_points` | true / 20000 | 出力用重点点群の有効化・点数上限。voxel方式専用の上限 |

単一センサーの入力、正の`input.voxel_grid_unit`、CPU直結の平面クラスタリングが必要。
入力時刻逆行・同時刻・frame_id変更・時間切れでは旧分類・セル履歴を破棄。現在入力のスコア計算は継続。
重点学習専用のセンサー原点・TF取得は不要。別機能の観測支持設定と点群座標変換は従来どおり。
センサーが移動する場合は入力を固定基準へ補正する必要あり。スキャン内の歪み補正や複数原点の合成には未対応。

## 確認用出力・互換性

`/downsampling/nonplane`はXYZの`PointCloud2`、best_effort・volatile・depth 1。入力と同じframe_id・stamp。
voxelモードでは学習回数と独立した、最大20,000点の出力用重点点群。実際の学習点列ではない。
セルスコアをセル内点数で割った重みで元点を非復元抽選し、同じ元番号を重複して出力しない。元データに同じXYZが複数ある場合は保持。
候補が十分なら非平面群16,000点・探索群4,000点。片方が不足した分は他方へ返却し、総候補不足なら実在する候補数で打切り。
この出力用の点数再配分は、学習側の80%という確率配分には影響しない。総学習は4,000回、重点学習は2,000回のまま。
学習と別の乱数で出力を生成し、同じ入力に対するAPI再取得は抽選結果を再利用。購読がない場合は出力用抽選を省略。
出力は残余点数に比例したセル重み更新とセル内部分シャッフルによる非復元抽選。全候補点の乱数・対数計算・順位付けなし。
元点単位の重み付き非復元抽選分布は維持。抽選順と乱数の対応は変更され、以前と同じ点列・グラフの保証なし。
セルの箱やスコアの可視化トピックはなし。機能・平面計算・デバッグ出力OFFではPublisherを作成しない。
DEBUGログにセル数・抽選数・非平面群のセル数/実抽選数・追加失敗数・準備時間を出力。通常ログの項目追加なし。
`mode: radius`で従来の距離方式へ戻せるが、その出力は実抽選点ではなく候補点全体。
新APIは`fuzzrobo/libgng/voxel_attention_api.h`へ分離。`gng_cpu`と`ais_gng`の再ビルドが必要。
入力設定→重点設定→`gng_exec()`の順。設定は実行1回限り、結果の添字と統計は次の入力設定または実行まで参照可能。
評価条件・計測・未検証：[検証資料](../../benchmarks/voxel_attention_20260925/README.md)。
速度削減と重点化の品質効果は別の評価。重点化OFFでも既存unknown重点枠が残るため、単純な一様学習との比較ではない。
