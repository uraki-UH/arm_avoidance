# 2026-09-23 - bsp3d版GNGの固定グリッド撤去と照合回数制限

## 1. 要約

既存tree版の独立コピーに、固定ノードグリッドの撤去と、全入力voxelに対する最近傍照合の回数制限を実装。Releaseの実bag比較で、入力voxel 0.1 mの平均処理時間を短い3試行では112.84→76.03 ms、連続300フレームでは114.94→83.47 msへ短縮。0.5 mでは追加処理の負担により53.46→73.61 msへ増加。全条件での高速化ではない。

元CPU版・既存tree版・bsp3d本体・通常ROS設定への今回分の編集なし。実装正本は[独立版README](../../../ais_gng_cpu/experimental/gng_bsp3d_sampled/README.md)。

- ノード管理をbsp3dのみに変更。入力範囲内のノード追加・移動・削除と座標キャッシュ更新を維持。
- 回数制限版で、全元点による観測寿命確認、未知物体・人の重点候補生成、全域探索を分離。
- 重点学習を入力voxel単位の候補選択と元点の厳密2近傍確認へ変更。確認済み近傍を学習時に再利用。
- 全域探索を入力voxel列の等分区間からフレームごとに巡回。選択済み点の処理順をシャッフルし、ノード上限時の位置偏りを抑制。

- `ais_gng_cpu/experimental/gng_bsp3d_sampled/`の独立ライブラリ2種。`pure`はグリッド撤去のみ、`sampled`は照合回数制限も有効。
- 観測用の疎な入力索引、探索回数と段階別時間の取得API、ノード格納・観測判定・重点配分のテスト。
- [再現スクリプト・設定・保存集計・SHA-256](../../../benchmarks/gng_bsp3d_sampled_20260923/README.md)。

探索枠削減時に、新規ノードが後続の全点照合を待って孤立削除される問題を抑制。追加時の近傍接続を設定。大量の同一点による重点学習枠の偏りは、voxel単位の候補選択で抑制。

**削除**

独立コピー内の固定ノードグリッド配列、1セル10ノード制限、`node.grid`に基づくノード配置制約を撤去。木の固定範囲検索・候補列挙・子セル並べ替えなし。

## 2. 条件・検証

- YAML範囲内の元点を観測に使用。入力点の追加除外や隠れた間引きなし。
- 観測寿命のリセットは全ノード近傍の実測点で判定。学習への採否・近傍順位から独立。
- 全域探索・接続更新の頻度と重点学習の配分が元版と異なるため、異方式間のグラフは非同一。`gng_getDownSampling()`のラベルには粗い重点候補を含む。
- エッジ寿命の加算は既存の学習処理を維持。ただし接続更新の頻度差があるため、同じ寿命推移の保証なし。
- `node.grid`はAPI互換のため受理するが、新しい2版ではノード管理・検索に不使用。入力voxelの設定は引き続き有効。

ROSトピック・メッセージ・launch引数の変更なし。新設定は独立C APIと比較用YAMLのみ。

| 設定 | 既定値 | 用途 |
| --- | ---: | --- |
| `sampling.max_probe_num` | 16000 | 1フレームの全域探索上限 |
| `sampling.min_cell_size` | 0.5 m | 元点観測索引のセル幅の下限 |
| `sampling.max_attention_trials` | 3 | 重点学習1枠の候補確認上限 |

`gng_get_sampling_statistics()`を追加。最近傍回数、ノード移動・観測・追加削除数、段階別時間などを取得。

`gng_cpu_container`内でReleaseビルド。`-O3 -DNDEBUG`、比較用の乱数とLPF時間刻み固定を使用。最終整形後の共有ライブラリは計測時とSHA-256一致。CTestは19/19件成功。最終ソース・設定・ライブラリの照合値を保存。

対象はMacnica交差点bagの`/lidar_points`。最大20000ノード、学習4000回、探索上限16000回、YAML範囲x/y±200 m・z -5〜10 m。約16万点／フレーム。以前の比較用YAMLスナップショットを使用し、現在稼働中ROSのパラメータとは別条件。コア単独の`gng_exec`時間で、ROS通信・TF・Viewer・外部分類器の処理時間は含まない。

短い比較は先頭30フレームを50更新分再利用し、先頭10更新を時間集計から除外。実行順を変えた3試行の平均値。

| input.voxel_grid_unit | 元グリッド | 既存bsp3d | グリッド撤去のみ | グリッド撤去＋回数制限 |
| --- | ---: | ---: | ---: | ---: |
| 0.1 m | 112.84 ms | 103.67 ms | 102.06 ms | **76.03 ms** |
| 0.5 m | 53.46 ms | 54.55 ms | 52.87 ms | **73.61 ms** |

0.1 mの新しい2版の内訳は、学習前処理64.83→36.50 ms、最近傍照合83576.85→21751.65回／フレーム。入力voxel処理は11.14→10.54 ms、学習5.33→8.30 ms、法線・ラベル10.73→10.62 ms。高速化の主因は前処理の照合回数削減。0.5 mでは元の入力voxel数が約15668個で探索上限とほぼ同じため、照合削減がなく、観測・候補生成の費用が増加。

入力には1フレーム約2.5万個の完全な原点座標が含まれる。原点の被覆だけで改善と判定しないため、全点評価に加えて原点以外の点も別集計。**GNGへ渡す入力からの原点削除は未実施**。被覆率は対象入力点から最近傍出力ノードまでの距離による評価で、エッジ形状の正確性を直接表す指標ではない。

| 短い比較・原点以外 | 元グリッド | 回数制限版 |
| --- | ---: | ---: |
| voxel 0.1 m・0.2 m以内の被覆率 | 76.75% | 78.04% |
| voxel 0.1 m・0.4 m以内の被覆率 | 94.98% | 95.74% |
| voxel 0.5 m・0.2 m以内の被覆率 | 60.82% | 63.68% |
| voxel 0.5 m・0.4 m以内の被覆率 | 97.95% | 98.37% |

探索上限4000・8000・16000回の0.1 m比較では、平均62.61・68.04・72.55 ms、0.2 m被覆率68.16・72.27・78.04%。細部被覆を維持する目的で既定値16000回を選択。各1試行の調整比較であり、上の3試行平均とは別集計。

さらに異なる300フレームを連続処理し、先頭50フレームを時間集計から除外。品質は25フレームごとに計算時間外で評価。

| 連続300フレーム・voxel 0.1 m | 元グリッド | 回数制限版 |
| --- | ---: | ---: |
| 平均処理時間 | 114.94 ms | **83.47 ms（27.4%短縮）** |
| 処理時間の95パーセンタイル | 128.10 ms | **133.61 ms** |
| 原点以外・0.2 m被覆率 | 75.71% | 77.16% |
| 原点以外・0.4 m被覆率 | 95.36% | 95.22% |
| 連結成分数の平均 | 79.27 | 39.45 |
| 最大連結成分のノード比率 | 88.51% | 91.03% |

平均時間は改善した一方、遅いフレームと0.4 m被覆の小幅低下あり。100 ms以内の継続実行を保証する結果ではない。

新しい2版の`node.grid=0.001, 1.0`を0.5と照合し、4条件×50＝200/200フレームのグラフハッシュ一致。各版・各voxel条件の3試行間でも150/150フレーム一致。異方式同士の一致ではない。格納テストでは旧1セル内の64ノード、移動・削除・ID再利用、±200 mの範囲を確認。観測判定はランダム点群の全走査との照合、重点配分は1000重複点を含む入力で検証。

起動したテスト・計測プロセスは全終了。ROSノードや再生の新規起動なし。既存プロセスへの停止・再起動操作なし。 作業前後の保存スナップショットで既存プロセスのPID変更を確認したため、作業開始時のPID維持を検証した結果ではない。一時ビルドは削除済み。ライブラリ、生ログ、フレーム別JSON、比較図は`artifacts/gng_bsp3d_sampled_20260923/`へ保存。

**制約**

- 入力分布とvoxel幅によって効果が異なる実験版。通常ROSへの組込みと既定バックエンド変更は未実施。
- 対象は1つのbag。既存ROSを動かした状態での壁時計計測のため、他プロセス負荷の影響あり。実環境の移動体認識精度・長時間安定性は未検証。
- 重点候補や寿命確認用の入力索引処理は残存。木への置換だけで全入力処理をなくす構成ではない。
- 密なエッジ配列2種は最大20000ノードで約2 GB。固定ノードグリッド撤去によるこの配列の削減なし。入力voxelの32 bit番号制約も残存。
- 比較ビルドの`GNG_DETERMINISTIC_BENCHMARK=ON`は実時間利用に不適切。実時間利用にはOFFでの再ビルドが必要。
