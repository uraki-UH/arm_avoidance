# 2026-09-24 - ViewerのClusters描画負荷削減

## 1. 要約

Clustersの個別メッシュを、箱・人用円柱と選択時の不透明度に応じた最大4組のインスタンス描画へ変更。速度矢印を1組へ集約し、選択無効時のクリック判定を未登録へ変更。

合成1,000クラスタ・矢印OFFでは描画要求2,000→4回、更新CPU 15.4→0.7 ms。矢印ONでは描画要求3,142→6回、更新CPU 38.9→1.4 ms。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 影響 | Frontendの表示処理。クラスタの生成・分類・GNG学習処理は対象外 |
| 保持 | 位置、回転、寸法、人・車の色、選択、表示ラベル、矢印の長さ・形状。topological_mapのBBox撤去も維持 |
| 条件 | Chrome headless・SwiftShader、合成100／1,000クラスタ、ノード・エッジOFF、30更新中央値 |
| 結果 | 回帰9件、非重複配置のピクセル一致、lint、Frontend本番ビルド成功 |
| 制限 | 半透明クラスタ同士の重なりは描画順によって混色が変化する可能性。実GPUと交差点全体のFPSは未計測 |
