# 2026-09-29 - 正解付き点群・勝者投票による平面検出評価

## 要約

入力点の正解を実GNGの学習時勝者へ投票する評価基盤を作成し、4シーン×3乱数種を実行。
今回の条件では、残差悪化判定撤去・接続長共通化の前後で全480フレームの平面所属出力が一致。一般的な同等性・改善の証明ではない。

- 正解付きCSV、解析形状manifest、ノード世代付き票分布、前後の所属・採点を保存。
- 正解は評価専用で、学習・平面判定への入力なし。各点1回の学習で重複投票を回避。
- 曲面を局所平面パッチとして扱うことはユーザー方針として許容。円柱のパッチ所属率を誤検出率とは扱わない。

## 条件・検証

各40フレーム×2,000点、合計96万点の入力、最大1,000ノード。下表は最初10入力を除いた30入力・3種の平均。
一致度は正解平面ごとの最大IoUの等重み平均。円柱シーンの正解平面は床のみ。

| 入力 | 平面macro best IoU | 平面点の未所属率 | 生点のノード被覆率（0.20 m） |
| --- | ---: | ---: | ---: |
| 観測欠落のある床 | 99.945% | 0.055% | 99.992% |
| 0.10 m段差＋壁 | 96.857% | 0.559% | 99.947% |
| 床＋円柱側面 | 99.045% | 0.531% | 99.949% |
| ノイズ標準偏差最大0.030 mの床 | 99.723% | 0.277% | 99.986% |

- 初期確定待ちを含む全40入力のIoUは順に94.959%、92.060%、94.046%、94.781%。開始直後の取りこぼしを隠さないため全区間値も保存。
- 円柱側面の平面パッチ所属率43.344%。曲面への受け渡し・再統合は未検証であり、平面所属自体を誤りとは判定しない。
- 通常3条件の投票なしノード率は約12.8～14.4%。これらには勝者支持による正解なし。生点被覆を別集計。
- GNG平均wall時間2.51～2.71 ms、現行平面平均thread CPU時間0.22～0.29 ms。CSV I/O・採点除外。実運用の2万ノード・ROS配信との比較不可。
- 評価器・生成器12テスト成功。床の種1でcapture ON/OFFとGTのみ変更した場合のグラフバイト一致を確認。
- 基本9条件は予測45秒・実測81.18秒、追加3条件は予測30秒・実測27.51秒。全12条件成功・cleanup_ok、試験プロセス終了、既存ROS維持。
- 通常ROS入力・重点サンプリングではなくGNG学習核の直接実行。移動物体・実センサー・曲面クラスタリングは評価対象外。
