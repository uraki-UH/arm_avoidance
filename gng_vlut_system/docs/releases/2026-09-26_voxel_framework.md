# 2026-09-26 - セル評価基盤をコンパイル時に選択可能

## 1. 要約

属性集計・任意の履歴更新・評価を共通化したヘッダーを追加。
GNGの把持／境界サンプリングとFVGの既存判定を接続し、不要機能は型特殊化・`if constexpr`で除外。
既定は拡張OFF。CMakeの属性・ファジィ・履歴を個別選択し、利用側も必要機能だけを要求可能。
ヘッダー用INTERFACE targetから構成を伝播し、FVGへのGNG実行ライブラリ依存は追加なし。
非平面・小平面・密度差の本番式や、撤去済みのオクルージョン削除は追加していない。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 仕様 | [共有セル評価基盤](../../../ais_gng_cpu/docs/sampling.md#セル評価フレームワークのコンパイル時拡張) |
| ビルド | `enable_voxel_framework`、`enable_voxel_fuzzy`、`enable_voxel_history`。いずれも既定OFF |
| 互換性 | 既存API・YAML・学習配分・把持／境界の判定を保持。FVGにgng_cpuのbuild依存を追加 |
| 型・命令 | 無効ポリシーの未使用型／関数を実体化せず、直接計算と同じ命令列。GNGの構造体サイズと本体`.text`も一致 |
| 実GNG | 同一bag・固定乱数の1,440フレーム比較で既存出力一致。既存経路の処理時間増加を検出せず |
| 単体 | OFF／全ON各CPU24件、ROS関連4件、中間3構成の実GNG API、不正構成の拒否が成功 |
| ROS | 通常配布先で16フレーム、候補一致と失効後の空出力を確認 |
| FVG | COLCON_IGNOREを保持した分離ビルドでOFF／全ON成功。実ROS入力の再検証は未実施 |

通常配布先のgng_cpu・ais_gngはOFFでビルド済み。既存プロセスへの強制適用・再起動なし。
全ONビルドだけで新しい重点条件が有効になるわけではない。式・属性・失効条件は利用側に必要。
履歴を実際に利用すればセル数に応じたメモリ・更新コストが必要。新機能の無償化や認識品質の保証ではない。
既存警告は残存。比較用コピーだけ乱数とdtを固定し、本番の時間・乱数処理は保持。
試験ノード・ベンチマーク・ビルドは全終了。既存bag・Viewer・3コンテナを維持。
詳細な条件・時間・起動コマンド・終了確認は[検証資料](../../../benchmarks/voxel_framework_20260926/README.md)に集約。
