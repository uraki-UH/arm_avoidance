# 2026-09-23 - bsp3dを使う独立GNG比較版

## 1. 要約

独立コピー`ais_gng_cpu/experimental/gng_spatial_tree`に、`bsp3d/include/bsp3d/bsp3d.hpp`の索引を使う`libgng_bsp3d.so`を追加。同じbag・YAML・Release条件でGNG本体は95.50 ms。固定順8分木112.04 msから約14.8%、グリッド103.94 msから約8.1%短縮。8分木版とのグラフハッシュは150/150フレーム一致。

- `bsp3d::Index`（`MovingBSPTree`）を索引に利用。既存GNGの学習・エッジ・寿命・ラベル処理は直前の最近傍2ノード版と共通。
- 追加・移動・削除を索引APIへ反映。特に移動は`updatePosition`経由とし、葉内の座標キャッシュとの不整合を防止。
- 2点用の固定長配列で`findNBest`を呼び出し、木全体の最近傍2点を取得。探索時の範囲列挙・子セルソートなし。
- bsp3dの3次元向け既定値を使用。葉32点、近似誤差`approx_eps=0`、実点群の境界箱による追加の枝刈りと更新は無効。ノード座標に沿った二分木、葉内の軸別座標配列、境界を作った祖先へ戻る移動経路を利用。

これらは実装上の違い。各要素単独の速度寄与は分離計測していない。

- 共有ライブラリ`gng_bsp3d`とAPIテスト8件。
- 既存の最近傍照合テストをbsp3dにも適用。
- bsp3d同梱の追加・移動・削除を混ぜた40,000操作の索引検証を、Release最適化と検証用assert有効の条件で実行。

今回の比較では固定順8分木より16.54 ms／フレーム短縮。

**削除**

なし。固定順8分木版・グリッド比較版も引き続き単独ビルド可能。

## 2. 条件・検証

- 元の`ais_gng_cpu/src/gng_cpu`、共通SpatialTree、bsp3d本体、YAMLへの今回分の変更なし。
- 最近傍2ノード方式のGNG処理を共通化し、索引だけをビルド時に切替。YAML以外の新しい点群フィルタなし。
- 同距離候補の選択順は索引に依存するため、任意の入力でのグラフ完全一致保証はない。今回の実bagでは一致を確認。
- 通常のROS launchへの組込み・インストール先ライブラリの置換は未実施。

ROS側の追加・変更なし。CMakeの`bsp3d_include_dir`はbsp3dヘッダーの場所。既定はワークスペースの`bsp3d/include`。

3方式すべてRelease、GNGライブラリは`-O3 -DNDEBUG`。`-march=native`・`-ffast-math`の追加なし。学習乱数とLPF時間刻み0.1秒を固定し、同じYAMLの適用値を確認。APIテスト24件、最近傍全走査照合2件、bsp3d索引テスト1件の計27件が成功。

同じbagの先頭30フレームを繰り返し50回入力し、先頭10回を除く40回を集計。各方式3試行、実行順はグリッド→8分木→bsp3d、8分木→bsp3d→グリッド、bsp3d→グリッド→8分木。

| 方式 | GNG本体平均 ms | 入出力込み平均 ms | 最終ノード数 | 最終エッジ数 |
| --- | ---: | ---: | ---: | ---: |
| グリッド | 103.94 | 106.52 | 19,925 | 51,660 |
| 固定順8分木 | 112.04 | 114.65 | 19,901 | 53,566 |
| bsp3d | 95.50 | 98.42 | 19,901 | 53,566 |

bsp3dの各試行平均は96.27／95.17／95.07 ms、本体p95は99.11／98.10／96.66 ms。入出力込みp95は101.97／100.93／99.64 ms。8分木版とのグラフハッシュは150/150フレーム一致。各方式の3試行間も全フレーム一致。既存の8分木版・グリッド版は前回の保存結果とも各50/50フレーム一致。

設定スナップショット・起動スクリプト・集計`summary.json`・SHA-256は[benchmarks/gng_bsp3d_20260923](../../../benchmarks/gng_bsp3d_20260923/)へ移管。共有ライブラリ・フレーム単位のJSON・ビルドログ・テストログはGit管理外の`artifacts/gng_bsp3d_20260923/`にローカル保管。再計測にはbagと共有ライブラリの別途準備が必要。[保存方針と前提条件](../../../benchmarks/README.md)。

実行した起動コマンド（コンテナ内）:

```bash
cmake -S /ros2_ws/src/ais_gng_cpu/experimental/gng_spatial_tree \
  -B /tmp/gng_bsp3d_build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build /tmp/gng_bsp3d_build -j2
ctest --test-dir /tmp/gng_bsp3d_build --output-on-failure --timeout 30
bash /ros2_ws/src/benchmarks/gng_bsp3d_20260923/run_benchmarks.sh
```

スクリプト内の計測コマンドは、各ライブラリに対して以下の形で実行。


テスト・計測セッションはすべて終了。新規ROSノードの起動なし、既存プロセスへの停止・再起動操作なし。

**制約**

GNGコアの直接API計測。ROS変換・TF・配信・viewer・外部分類器の時間は含まず、全ROS系の10 Hz動作保証ではない。CPU固定なし、既存処理との競合を含む。実bagの視覚的品質は未評価。

葉内座標の直接変更は不可。ノード移動時は索引APIへの反映が必須。索引の差替えであり、固定グリッド管理・セル当たりの容量・密なエッジ行列のメモリ制約は従来どおり。

比較用の既定`GNG_DETERMINISTIC_BENCHMARK=ON`で保存したライブラリ。実時間動作用にはOFFで再ビルド。ビルド・仕様の正本は[独立版README](../../../ais_gng_cpu/experimental/gng_spatial_tree/README.md)。

処理別のボトルネックと計測負荷は[追加調査](../designs/gng_bsp3d_profile_20260923.md)に記録。
