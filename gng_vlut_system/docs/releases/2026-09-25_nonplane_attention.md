# 2026-09-25 - 非平面重点サンプリングの評価・撤去

## 1. 要約

追加した非平面重点サンプリングを、ユーザー指示により削除。
設定OFFへの変更だけでなく、voxel・radius両方式の実装と専用出力を撤去。

- 非平面・新規占有・表現不足のスコア、履歴照合、追加抽選、対象ノード保持を削除。
- `/downsampling/nonplane`と`enable_nonplane_attention`・`nonplane_attention.*`を廃止。
- 専用API・ヘルパー・単体テスト・旧専用ベンチを削除。評価資料と実測ログは保持。
- 既存unknown重点学習・把持重点・境界重点・通常エイジングは維持。
- 平面クラスタと非平面成分抽出・出力は維持。成分出力OFF時の重点用抽出も不要。
- `at128.yaml`の総学習4,000回、入力ボクセル幅、ノード上限は変更なし。

削除判断は追加計算コストと品質比較によるもの。一般的な重点学習の恒久禁止ではない。
局所密度制御の未実施部分は[保留記録](../pending.md)、今回の撤去は[判断記録](../reject.md)を参照。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 移行 | `gng_cpu`と`ais_gng`を再ビルドし、使用中のGNG launchを再起動 |
| 独自設定 | 廃止した`enable_nonplane_attention`・`nonplane_attention.*`を独自YAMLから削除 |
| API互換性 | `voxel_attention_api.h`と専用3 API、非平面用unknown無効化APIを廃止。利用側は再ビルドが必要 |
| 通常学習 | 追加方式で置換していた既存unknown混合へ復帰。単純な一様学習への変更ではない |
| 既存設定の注意 | at128の`node.unknown_learning_rate: 0.3`は既存受付範囲外。候補あり時は既定5による80%枠。今回はこの設定仕様の変更なし |
| CPU検証 | 削除後21対象の回帰テスト成功。unknown候補有無、把持・境界共用API、統計・エイジング等を含む |
| ROS検証 | 把持・境界重点と非平面成分抽出の3対象成功。通常配布先で実bag12フレーム×3条件成功。非空Tmap・成分所属・廃止PublisherとROSパラメータの不在を確認 |
| ビルド | コンテナ通常配布先の`gng_cpu`・`ais_gng`成功。既存の符号比較等の警告あり |
| 実行環境 | 全試験プロセス終了。既存GNG・bag・ViewerのPIDとコンテナ稼働状態を維持。新バイナリの反映には使用中launchの再起動が必要 |
| 復旧資料 | 削除前の関連ソースを`artifacts/nonplane_attention_removal_20260925/source_before.tar.gz`へ退避。Git対象外 |

削除前の評価（2026-09-25）：10万入力点・実bag完了2試行平均のprocessingは、
高速化前ON 65.569 ms、高速化後ON 63.803 ms、高速化後OFF 56.914 ms。
受信待ち・描画は対象外。第3試行の最終条件は600秒上限で中断し、集計から除外。
合成移動曲面ではOFFが優位。実bagの意味正解・追跡品質・Viewer目視での改善は未検証。

当時の最適化単体・ROS検証の成功は、機能の採用価値の確認とは区別。
過去の性能数値は削除後バイナリの新規測定値ではない。
詳細な比較条件・失敗・限界は[ボクセル方式の評価記録](../../../benchmarks/voxel_attention_20260925/README.md)へ集約。
半径方式の候補・重み一致と検索高速化は[当時の記録](../../../benchmarks/nonplane_attention_20260925/README.md)を参照。

削除後の起動・検証コマンド：[削除後検証](../../../benchmarks/nonplane_attention_20260925/REMOVAL.md)。
