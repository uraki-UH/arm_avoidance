# 2026-09-25 - 非平面連結成分の近傍への重点サンプリング

## 1. 要約

CPU GNGに、一定点数の非平面連結成分へ学習回数を配分する機能を追加。
単独・小成分は重点候補から除外し、元グラフ・通常学習・非平面成分出力には保持。
動静判定・時間履歴による安定性判定・FVGの追加なし。

- CPU直結の平面未所属成分を一度抽出し、出力と次フレームの重点対象へ共用。
- 前回の対象ノード近傍にある現在の入力点を選択。ノード座標そのものの再学習なし。
- 境界重点と同じkd-tree・距離ガウス重みを再利用。近接する対象ノード数による重複加算なし。
- 同日高速化：広がりの大きい軸で分割し、末端の包囲箱で枝刈り。末端16点の連続走査により再帰回数を削減。
  全入力点・採否半径・ガウス重みを保持。境界重点も共通検索の高速化対象。
- 総学習回数は固定。ON時は既存unknown重点枠を置換し、重点枠の残りは全体voxelから抽選。
- 把持・境界重点との併用時は各枠を混合し、設定比率の合計が1に達する設定を拒否。
  候補のない枠は全体学習へ返却。非平面機能OFF時は従来のunknown混合へ復帰。

`at128.yaml`では重点化と候補点群出力を有効化済み。他のセンサー設定・ノード既定値はOFF。
使用中のlaunchを再起動して反映：

```bash
ros2 launch ais_gng ais_gng.launch.py \
  backend:=cpu lidar:=at128.yaml input_topic:=/lidar_points
```

## 2. 条件・検証

| 設定・項目 | 内容 |
| --- | --- |
| `enable_nonplane_attention` | ON/OFF。CPU直結平面計算OFF時は警告して無効化 |
| `nonplane_attention.min_component_nodes` | 5。重点対象の成分ノード数、設定範囲2〜65,534 |
| `nonplane_attention.radius` | 0.3 m。対象ノードとの距離による候補選択、固定半径 |
| `nonplane_attention.ratio` | 0.5。総学習回数中の重点枠。4,000回なら候補あり時2,000回 |
| `nonplane_attention.timeout_sec` | 0.5秒。入力時刻差と実時間の経過を両方確認 |
| `nonplane_attention.enable_debug_points` | `at128.yaml`ではtrue、ノード既定false。機能ON時に`/downsampling/nonplane`を生成、購読時だけ点群化 |
| 点群出力 | XYZのPointCloud2、best_effort・volatile・depth 1。入力のframe_id・stampを保持し、候補失効時は空点群 |
| 失効 | 初回・候補なし・期限切れ・同一時刻・時刻逆行・frame_id変更では旧候補の再利用なし |
| 対応 | 単一入力点群。同一frame_idの前回結果を使用。センサー移動時は固定基準へのTF補正が必要 |
| 出力OFF | `nonplane_component.direct_enabled: false`でも重点用の内部成分抽出は継続 |
| 統計 | 重点再学習を独立観測とみなさず、共分散・観測支持・統計用勝者イベントへの加算なし |
| 互換性 | 起動時設定のみ。CPUの新API追加により`gng_cpu`と`ais_gng`の再ビルドが必要 |
| 単体検証 | ROS側22テスト成功。線状・平面状・重複点・半径境界を全探索と完全照合。CPU API・索引試験2対象は初期実装時に成功 |
| ROS検証 | 実bag入力で候補XYZを独立近傍計算と照合。小成分除外・時刻逆行・座標変更・候補なし・機能OFF・平面OFF・成分出力OFF・候補出力OFFを確認 |
| 追加コスト | 100,000入力点・6,654対象点・17,764候補点で20.219→11.977 ms、約41%短縮。CPU 0固定、各7回中央値の3試行中央値 |
| 追加照合 | 別の3フレームでも候補・重みが完全一致、処理時間36〜48%短縮。測定は木構築・検索・重み混合のみ、GNG全体・ROS配信・描画時間は含まない |

点数による「散発的」の近似であり、物体種別や実在性の判定ではない。
小さい人・細い物体も重点対象外となる可能性あり。近傍の床や小成分の入力点が対象半径に入る場合あり。
大きな木などの成分別配分上限、動静判定、局所ノード密度の保証は今回の対象外。
デバッグ点群は重点候補であり、入力範囲フィルタ後の最終集合や各反復で実際に抽選された点の履歴とは別。

初回はAPI公開漏れ、テストの旧ライブラリ参照・警戒距離不足、ROS初回未到着を検出。修正後に再検証成功。
高速化時の実bag照合では試験の初回再送が二重学習を招き不一致。再送を接続待ちへ置換後、全6条件で成功。
SciPyとNumPyのバージョン互換警告あり。候補照合の全条件は成功、実Viewer目視と認識品質改善は未検証。
通常起動用コンポーネントのビルドと配布先での再試験を実施。ROS試験前後のバイナリ一致を確認。
全試験ノードは終了、既存GNG・bag・Viewerの停止なし。
