# 2026-09-11 - graspnetの未知物体ノード密度調整

## Summary

`graspnet.yaml`の未知物体に対するノード追加抑制半径を1cmから3cmへ変更。

## Changed

- `node.interval`を`[0.1, 0.2, 0.2, 0.03]`へ変更。
- ノード上限3,000個、学習回数5,000回、他ラベルの抑制半径は維持。

## Added

設定コメントへの単位と用途の明記。

## Fixed

未知領域への過密なノード追加の緩和を目的とした設定調整。

## Removed

なし。検討中の内部追加順変更は適用せず、検証用の一時テスト追加も撤回。

## Behavior Impact

- 近傍の未知物体ノードが追加を抑制する範囲の拡大。細部の表現密度低下とのトレードオフ。
- 目標ノード間隔そのものではなく、既存ノードからの距離に基づく追加抑制。
- 上限到達時の強制再配分なし。偏りや追従不良の解消を保証するものではない。
- `d435.yaml`および稼働ノードのパラメータは変更なし。

## Topics / Params / Messages

- `ais_gng/config/gng_cpu/graspnet.yaml`の既存パラメータのみ変更。
- 新規パラメータ、トピック、メッセージ、launch引数なし。

## Verification

- YAML値とGNG実装の`node.interval`解釈を確認。
- 実点群での変更後の比較は未実施。通常の`lidar:=graspnet.yaml`起動で適用。

## Risk / Notes

細い持ち手などのノード数が減る可能性。改善量の実測後に半径を再調整。
