# 2026-09-28 - 経路計画と目標タスクの構成切替

## 1. 要約

共有計画ノードの経路探索と通常目標選択を、実装を差し替えられる部品へ分離。
起動時設定`graph_planner`と`goal_task_components`を追加。既定構成は従来の一括探索・指定目標優先・条件付き安全退避。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 影響 | 起動設定で計画器と目標タスクの構成を選択。未知の名前と起動後の変更は拒否 |
| 移行 | 既存設定の変更は不要。独自C++呼出し元は新しい抽象計画器に対応が必要 |
| 対象 | GNG経路と通常目標選択。試行状態・連続軌道・把持工程管理は対象外 |
| 結果 | 通常ビルド・CTest 2対象12試験成功。独自部品注入と従来の安全条件を検証 |
| 初回失敗 | 到達不能の欠損キー・空列を同一視しない新規試験を契約に合わせて修正 |
| 未検証 | ROS・Gazebo・実機の実動作 |
| プロセス | ビルド・試験は全終了。ROS起動・既存プロセス停止なし |

設定値、拡張方法、起動コマンド：[差し替え仕様](../planning_components.md)。
