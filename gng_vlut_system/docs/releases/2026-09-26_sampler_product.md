# 2026-09-26 - GNGサンプラーの開発・製品配布境界

## 1. 要約

内部のサンプリング拡張性を残し、製品SDKからの任意評価器の注入をコンパイル時に禁止可能。
把持・境界の評価器をCPUライブラリ側へ移し、ROS側は領域と配分などのデータだけを入力。
抽選本体と既存の学習配分・候補出力を維持。

- `allow_external_sampler`を追加。開発環境との互換性のため既定ON、製品配布は明示OFF。
- 製品版は外部規則登録・元点番号指定・任意重み指定の3関数を宣言と公開シンボルから除外。
- 製品SDKから拡張ヘッダー2個とテンプレート用の公開CMakeターゲットを除外。
- `enable_voxel_*`の機能選択とは独立。内部機能を有効化しても外部登録権限は復活しない。
- 組込み入力の配列をライブラリ側で所有し、入力・1実行ごとの失効と不正入力時の解除を維持。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 対象 | `gng_cpu`、CPU用`ais_gng`と製品SDK |
| 新API | `gng_set_builtin_sampling`、承認済みの把持AABB・境界位置・半径・配分 |
| 除外API | `gng_set_sampling_rules`、`gng_set_priority_input`、`gng_set_weighted_priority_input` |
| 既存設定 | ROS YAML・トピックと通常開発ビルドを維持 |
| 必要操作 | 変更した両パッケージの再ビルド、使用中GNGの再起動 |
| 製品配布 | 開発用ファイルと混在しない専用build/install先。開発ヘッダー残存時はinstall拒否 |
| CPUテスト | 開発25件・製品22件が成功。構成依存の3件は製品対象外 |
| ROS関連テスト | 開発4件・製品2件が成功。製品SDKのみを使ったCPU ROSビルド成功 |
| SDK監査 | 正規利用成功、宣言自作・マクロ変更による外部API復活不可、上書き前のinstall拒否 |
| 実GNG | 変更前・開発・製品の960フレーム分で時間以外の公開出力が一致 |
| ROS実行 | 各16フレームの候補一致・失効、製品再試験16フレームで実ロード先も一致 |

重点ありの平均全体時間は変更前42.17 ms、開発41.82 ms、製品41.79 ms。
対象は80フレームの先頭20を除く2試行平均で、登録処理を含む入力・学習・出力取得。
共通の既存bag/Viewer稼働下であり、全条件の性能保証や新規ラベルの認識品質検証ではない。
製品ROSの初回試験は開発コンポーネントを誤読込。読込先検査で検出し、本体追加ビルド後に再検証。

旧外部APIへリンクした利用側は製品版と非互換。動的プラグインローダーの追加ではない。
独立FVGパッケージのビルドには開発ヘッダー・ターゲットが必要で、製品SDKだけでは不可。
製品でも領域や配分などのデータは変更可能。全設定の固定・入力改変の防止は対象外。
OS管理者によるバイナリ置換・解析への対策、ライセンス認証やGPU・別OSでの検証は未実施。

通常install先は開発ON・機能拡張OFF。製品版は検証専用の分離先へ配置。
自分で起動した試験ノード・比較・ビルドは全終了し、既存bag・Viewer・3コンテナを維持。

起動コマンド・実測・制約：[再現記録](../../../benchmarks/sampler_product_20260926/README.md)。
