# 2026-09-24 - CPU GNGの未使用対応表とソートの削除

## 1. 要約

学習・通常出力で未使用の`voxel2node_ids`について、配列確保・書込み・ソートを削除。
上限20万点の設定では、対応表の確保1.6 MBも不要。

| input.voxel_grid_unit | 全体：削除前→後 | 照合・重点候補区間：削除前→後 |

| 0.1 m | 93.319→88.383 ms | 69.675→65.054 ms |
| 0.5 m | 32.444→32.460 ms | 11.261→10.929 ms |

0.1 mは全体5.3%短縮。0.5 mは区間短縮のみで、全体の改善は未確認。
