# HTML ROS Publisher再接続所有者の統一

## 変更内容

- HTMLのROS再接続処理を点群Publisherの唯一の再接続所有者として使用
- `ROSLIB.Topic`内蔵の自動再接続を無効化
- `callOnConnection`をROSオブジェクトへ束縛し、ローカルROSLIBの未束縛呼出しを回避
- 同一originで複数タブを開いた場合、前面タブだけが各点群トピックをpublishするリース制御
- 同一originでrosbridgeへ接続するHTMLタブを1個に限定するリース制御
- リアルタイムGNG再生中の重い法線・クラスタ更新を停止時の確定処理へ分離
- リアルタイムGNGの1回あたり学習量を実行時間に応じて自動調整
- 初期GNG-WASM一括学習を64ステップ単位の非同期実行へ変更

## 期待する挙動

- WebSocket切断後に古いTopicの再広告処理を残さない構成
- 再接続後の点群Publisherを1個だけ生成
- トピック名、メッセージ型、送信レート設定の互換維持
- タブ切替・終了後、最大1.5秒で次の前面タブへpublish所有権を移譲
- 背面タブのWebSocketを即時closeし、rosbridge接続の重複を防止
- GNG再生中もPointCloud2送信タイマーを長時間停止させない構成
- 設定学習量を維持しつつ、再生時のUIスレッド専有時間を抑制
- 初期学習中もROS送信とブラウザ描画を停止させない構成
