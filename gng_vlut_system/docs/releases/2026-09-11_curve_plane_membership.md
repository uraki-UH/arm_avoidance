# 2026-09-11 - 平面由来パッチの曲面所属の整合

## Summary

同じ元平面内の不要な曲面分断と、取っ手の根元の混入による曲面成長の阻害への対処。
元の平面クラスタ・GNGノード・メッセージ形式の変更なし。

## Changed / Fixed

- 同じ元平面内で短い実GNGエッジにより接続する曲面領域について、全所属点の再フィットによる統合検査。鋭い境界・点残差・パッチ残差・法線・曲率の検査は維持。
- 二つの追跡核の統合後は参照集合の再構築。元平面数が減った場合も、成立済み曲面の表示資格の継承。
- 既存追跡核に未保持領域を追加する場合は、旧係数への適合検査と旧参照集合の維持。新規ノードIDによる支持率の水増し防止。
- 全体不適合時は、高品質な位置支持を持つパッチからの局所成長。混入で大きくなった低品質パッチの先取り抑制。
- 平面由来パッチ全体の追加が不適合の場合だけ、成立済み曲面に適合し、実エッジで到達可能な部分の抽出。既定の距離条件は4 mm、法線整合条件も使用。
- 部分抽出後は中心・曲率・接続位置での境界分類を再評価し、全点の再フィット成功時だけ所属を更新。残余は別曲面の探索または未確定領域として保持。
- 適合する隣接パッチの一括再フィットによる計算予算消費の抑制。追加推定も既存の`max_model_fits`予算内。

## Behavior Impact / Topics / Params / Messages

- 新規launch引数・YAML項目・topic・message fieldの追加なし。
- 「同じ元平面なら無条件に同じ曲面」ではなく、幾何適合を伴う統合・部分分離。
- 支持領域の離隔・自由空間・鋭い境界による分離は継続。二つの追跡核を再統合したフレームでは新しいIDへの切替。
- 共有ライブラリのビルド済み。既存の曲面処理ノードへの反映には再起動が必要。作業中の既存ROSプロセスの停止・再起動なし。
