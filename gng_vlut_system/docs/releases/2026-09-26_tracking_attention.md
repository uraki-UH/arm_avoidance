# 2026-09-26〜28 - 非平面重点サンプリングと軽量方式への切替

## 1. 要約

9月26日に粗いセルの密度不足・重心ずれ評価を追加。9月27日のユーザー指示で本番を軽量方式へ切替。
既存の最近傍ノードID＋生成世代を前回非平面所属と照合し、一致セルへ点数比例で配分。
`at128.yaml`は`nearest_nonplane`・配分50%・フレーム保持なし。粗いセルの追加集計は停止。

9月28日に試作した26近傍拡張は、同日のユーザー指示により実装・API・設定受付・専用テストを撤去。
`adjacent_nonplane`は使用不可。従来の`nearest_nonplane`と`coarse`は維持、at128の変更なし。
[撤去前の測定記録](../../../benchmarks/tracking_attention_20260926/ADJACENT.md)。

- 軽量方式は非平面近傍の重点化であり、密度不足や移動先を直接検出する方式ではない。
- 元点の複製・追加ソート・追加近傍探索なし。粗いセル統計・26近傍支持を省略。
- OFFは`if constexpr`による点単位処理の除外。ONの追加コストは存在。
- 総学習回数を維持し、候補がある場合だけ設定割合を重点学習へ配分。
- `/downsampling/tracking`へ抽選対象の元点群を配信。購読時だけ候補を展開。
- ノード追加・削除・オクルージョン判定・動静分類は今回の追加対象外。

機能の宣言既定値はOFF、`at128.yaml`はON。旧方式は`mode: coarse`と明示配分で利用可能。
合成試験の軽量方式は小幅改善のみ。実bagの認識品質や追従精度の改善保証はなし。
実bagでは非平面所属から候補点群までの接続を検証、正解軌跡による品質評価は未実施。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 設定 | `enable_tracking_attention`、`tracking_attention.*`。起動時読込 |
| 設定例 | `ais_gng_cpu/src/ais_gng/config/gng_cpu/at128.yaml` |
| 方式 | ROSのmode既定nearest_nonplane、ratio既定0.5。APIのmode省略時はcoarse |
| 有効化条件 | CPU版・単一入力・平面／非平面所属の計算ON |
| 点群出力 | 機能ONかつ`enable_pointcloud: true`。点群出力設定のみ既定true |
| 点群の意味 | 重みが正の候補集合。実抽選点列・確率値・固定点数ではない |
| QoS | `PointCloud2`、Best Effort、Volatile、depth 1 |
| 座標系 | 同じ周期のGNG出力ヘッダー・変換済みXYZ |
| 所属 | 前回非平面ノードのID＋生成世代。一般のGNGラベルとの混同なし |
| 失効 | 初回、frame不一致、同一stamp／巻戻し、期限超過、複数入力 |
| ABI | 公開構造体の末尾拡張。ライブラリと利用側の再ビルドが必要 |
| 製品版 | 組込み条件は利用可能。任意サンプラーの外部登録制限は維持 |

通常配布先へReleaseビルドを反映。9月27日の軽量方式は開発CPU25件、ROS関連5件、製品CPU22件が成功。
粗い方式の回帰に加え、軽量規則・voxel OFF・古いノード世代・未知mode・固定学習枠を検証。
実bagで候補受信と失効を確認。点群のViewer実描画・人／車の認識精度は未検証。
OFF時の同値性、合成追従、区間別時間、失敗記録は測定資料へ集約。

試験は独立ROSドメインで実施。試験ノードは終了時に停止し、既存bag・Viewerを維持。
既存GNGは停止・再起動せず。設定は起動時読込で、旧プロセスには再起動が必要。
最終確認では作業中に起動されたGNGの軽量mode・新版ライブラリ読込を確認。
