# 2026-09-26 - 粗いセルの密度不足・重心ずれによる重点サンプリング

## 1. 要約

CPU GNGの共通抽選へ、非平面近傍の表現不足を評価する組込み条件を追加。
セル内の点数とノード数の比、および両者の重心ずれから重点配分を決定。
ユーザー指定の0.5 m／1 mを設定可能。入力voxel・ROI・world bucketの幅は独立。

- 単なる非平面全域の重点化ではなく、表現不足かつ自セル・隣接セルの非平面支持を条件化。
- 元点の複製・追加ソートなし。既存入力集計ループへセル統計を併合。
- OFFは`if constexpr`による点単位処理の除外。ONの追加コストは存在。
- 総学習回数を維持し、候補がある場合だけ設定割合を重点学習へ配分。
- `/downsampling/tracking`へ抽選対象の元点群を配信。購読時だけ候補を展開。
- ノード追加・削除・オクルージョン判定・動静分類は今回の追加対象外。

ノードの宣言既定値はOFF、`at128.yaml`のみユーザーの目視確認依頼によりON。
今回の合成入力で追従誤差の改善を確認できず、速度・認識品質の改善保証はなし。
実bagでは非平面所属から候補点群までの接続を検証、正解軌跡による品質評価は未実施。

## 2. 条件・検証

| 項目 | 内容 |
| --- | --- |
| 設定 | `enable_tracking_attention`、`tracking_attention.*`。起動時読込 |
| 設定例 | `ais_gng_cpu/src/ais_gng/config/gng_cpu/at128.yaml` |
| 有効化条件 | CPU版・単一入力・平面／非平面所属の計算ON |
| 点群出力 | 機能ONかつ`enable_pointcloud: true`。点群出力設定のみ既定true |
| 点群の意味 | 重みが正の候補集合。実抽選点列・確率値・固定点数ではない |
| QoS | `PointCloud2`、Best Effort、Volatile、depth 1 |
| 座標系 | 同じ周期のGNG出力ヘッダー・変換済みXYZ |
| 所属 | 前回非平面ノードのID＋生成世代。一般のGNGラベルとの混同なし |
| 失効 | 初回、frame不一致、同一stamp／巻戻し、期限超過、複数入力 |
| ABI | 公開構造体の末尾拡張。ライブラリと利用側の再ビルドが必要 |
| 製品版 | 組込み条件は利用可能。任意サンプラーの外部登録制限は維持 |

通常配布先へReleaseビルドを反映。開発CPU25件、ROS関連4件、製品CPU22件が成功。
粗い境界を跨ぐvoxel、voxel OFF、負座標、古いノード世代、無効設定、固定学習枠を検証。
実bagで候補受信と失効を確認。点群のViewer実描画・人／車の認識精度は未検証。
OFF時の同値性、合成追従、区間別時間、失敗記録は測定資料へ集約。

試験は独立ROSドメインで実施。試験ノードは終了時に停止し、既存bag・Viewerを維持。
ユーザー稼働中のGNGは停止・再起動せず、新しい出力設定の反映には再起動が必要。
起動コマンドと終了確認は下記の再現資料を参照。
