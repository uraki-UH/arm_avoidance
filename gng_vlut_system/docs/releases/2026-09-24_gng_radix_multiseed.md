# 2026-09-24 - CPU GNGの基数ソート採用と複数シード検証

## 1. 要約

本番CPUの入力voxelソートを、全32bitセル番号による安定な4パス基数ソートへ変更。6シードの同一bag比較で、0.1 mは108.239→101.569 ms、0.5 mは39.828→35.947 ms。今回のデータで明確な学習品質悪化を確認せず、本番へ反映。

ユーザーの「ランダム性の問題なら気にしなくてよくない」と追加検証への承認に基づき、固定シードのグラフ完全一致を必須とした以前の判断を見直し。[旧判断](../reject.md)は履歴として保持。

- `ais_gng_cpu/src/gng_cpu`の入力ソートをBoost整数ソートから安定基数ソートへ変更。入力上限に合わせた作業バッファを初期化時に確保し、フレーム間で再利用。上限20万点で約1.6 MB。
- 量子化、セル割当、入力の採否、全点照合、重心の計算式、学習4,000回、重点配分、ノード・エッジ更新、クラスタ処理は維持。
- 本番の乱数と時間刻みは従来どおり。比較版の固定シード・固定時間・計測APIの混入なし。

- 本番に全32bit順序・同値キーの安定性・元点保持・末尾保護のソートテスト。
- 独立比較コピーにシード指定と観測代表点切替を追加。比較用コピーは`COLCON_IGNORE`で通常ビルドから除外。
- [6シードの再現手順と集計](../../../benchmarks/gng_radix_multiseed_20260924/README.md)。

- ソート結果の完全一致だけで確率的GNGの採用可否を判断していた評価方法。シード間の品質ばらつきとの比較へ変更。

## 2. 条件・検証

同じセルの入力順を保持するため、旧Boost版と重点候補の並びや重心の浮動小数点加算順が変化し得る。固定した乱数でも選択点・グラフの完全一致は保証しない。

6シードの0.2 m被覆率は、0.1 mで77.3682→77.4576%、0.5 mで60.1714→60.1126%。平均差+0.0894／−0.0588ポイントは、Boostのシード間標準偏差0.1387／0.1540ポイントより小さい。平均最近傍距離の差は−0.248／+0.154 mm。平均ノード数・平均エッジ長の方式差も、対応するシード間標準偏差内。

観測代表点はソート済みセルの先頭で、radixでは元入力番号最小の実測点。代表点の角度差は量子化・乱数だけの変化ではない。初回のp95角度差は0.1971°／0.7664°、最大0.7981°／3.5841°。同じセル内の実測点という仕様は維持。[観測仕様](../../../ais_gng_cpu/docs/observation_support.md)。

代表点だけの変更と観測ON/OFFによる対照試験では、全240フレームのグラフ・接続・クラスタ・入力ラベルが一致。観測出力は変化するが、GNGの学習判断への帰還なし。

変更なし。公開C APIのエクスポート集合も一致。従来のlaunch・YAMLを使用可能。

- 6シード×2幅×2方式×200フレームと、観測対照8条件×30フレーム、計5,040フレーム。全フレーム4,000回学習。
- 2,400組で全元点のセル対応、セル数、保持点数、整列セル番号列、セル区間が一致。
- 既定シードの計800フレームで、前回保存済みの各方式とグラフ等が一致。
- Release＋LTOで比較版34件、本番17件、計51件のテストが成功。観測APIの画素参照・圧縮索引・レイ復帰経路を含む。
- インストール済みの実時間・非固定乱数版で、実点群30フレーム、重点入力・観測・統計・イベント・差分有効の動作確認が成功。
- 実際の引数なし`cb`で全30パッケージが55.6秒で成功。`gng_wasm_core`のstderr出力あり、失敗・中断なし。`colcon list`は30件、`gng_cpu`は通常版1件。
- 本番ライブラリを同一ディレクトリ内の原子的置換で反映。公開API不変、Releaseの`-O3`・LTOを確認。

既存`gng_cpu_container`内で起動した主要コマンド:

```bash
bash /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/build.sh
bash /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/run.sh
python3 /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/summarize.py
bash /ros2_ws/src/benchmarks/gng_radix_multiseed_20260924/install_validated.sh
bash -ic cb
```

有限タイムアウト付きで実行。全プロセス終了、一時ビルド削除済み。既存ROS関連9プロセスはPID・親PID・コマンドが前後一致。既存Viewer・bag再生の停止・再起動なし。

**制約**

単一bag・6シードの評価。被覆率の差が小さいことを、全環境での同等性や認識精度の保証とは扱わない。実bagの観測量比較はレイ経路で、実depthの画素表を使う品質比較は未実施。ROS配送、分類器、Viewer描画は計時外。

本番の元ライブラリは`artifacts/gng_radix_multiseed_20260924/production_before.so`、新ライブラリと生データも同ディレクトリに保存。比較スクリプト・集計・ハッシュは`benchmarks/gng_radix_multiseed_20260924/`。
