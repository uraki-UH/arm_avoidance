# 2026-09-09 - 重複ラベル優先順位の長押しドラッグ

## Summary

重複ラベルと原因別ラベルの並べ替えを、長押しドラッグと「先頭へ」に統一。

## Changed

- 項目枠全体の350 ms長押し、または押下位置から8pxを超える移動でドラッグ開始。相手の項目に重ねて離した時点で確定。
- 相手より元の位置が上なら相手の下、元の位置が下なら相手の上へ挿入。項目の上半分・下半分による分岐なし。
- 挿入線は結果の予告。線や隙間を狙う必要なし。隙間へのドロップも従来どおり可能。
- 掴める項目枠に常時1pxの輪郭と薄い背景を表示。ホバー時は輪郭を明るく、押下時は水色の枠とリングで強調。
- 「先頭へ」は不透明な背景と明確な枠線を使用。先頭で無効の場合も枠を維持し、背景・文字色のみ変更。
- 掴める目印として左側に手でつかむ形の `HandGrab` アイコンを表示。6点マークから置換。アイコンは装飾のみで、操作範囲は引き続き項目枠全体。
- 色入力・チェックボックス・先頭移動ボタンはドラッグ対象外。ラベル文字や枠の余白、展開見出しからの移動に対応。展開見出しは短いクリックで開閉、長押しでドラッグ。
- 掴んだ項目名の追従表示と、元の行の半透明表示。
- 親グループ間・同じ親内の原因間のみの移動。別グループの相対順・表示状態・色は維持。

## Added

- 先頭へ移動するボタン。キーボードの通常ボタン操作にも対応。
- 専用コンポーネント `LabelPriorityList` と挿入順序の純粋関数。
- 実ブラウザによるマウス・タッチ操作の検査。

## Fixed

- リスト外のドロップ、Esc、フォーカス喪失、pointercancel、モーダル終了時のキャンセル。
- 長押し成立前の移動によるキャンセルを廃止。押してすぐ動かす操作でも並べ替え可能。
- 短いクリックは通常のON/OFF、長押し後のクリックは抑止。ドラッグによる誤切替を回避。

## Removed

上下に1段ずつ移動するGUIボタンと、6点グリップだけに操作範囲を限定する方式。通常のON/OFFボタン・色入力は維持。

## Behavior Impact

- 並べ替えの確定はドロップ時のみ。ドラッグ途中の地図描画設定の変更なし。
- 親OFF時の原因別コントロールは従来どおり無効。
- 表示優先順位は既存の `node_label_priority` を使用。

## Topics / Params / Messages

ROS・WebSocket・GNG判定処理の変更なし。
