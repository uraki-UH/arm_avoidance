# 位置偏差による局所曲率推定

## 変更範囲

- `/curved_surface_clusters/markers` の前段となる局所曲率・境界接平面推定の位置ベース化。
- GNG学習・`plane_clusters`・`nonplane_components` の生成処理は変更なし。
- 既存の法線変化による局所推定の置換。外部ライブラリの追加なし。
- 候補全体のモデル推定・法線整合ゲート・追跡成立条件は維持。パイプライン全体からの法線除去ではない点に注意。

## 構築方法

1. パッチ内の有限ノード位置からPCA基準平面と面内座標の構築。
2. 面内広がりによる座標の正規化と、符号付き高さへの `h = au² + buv + cv² + du + ev + f` の当てはめ。
3. 面内セルの所属数による密度重みと、最大4回のHuber重み付きQR。収束時の早期終了、悪条件時の全体SVDへの切替。
4. 一次係数を含む傾斜補正と、実接平面の正規直交基底での曲率テンソル・主曲率算出。
5. 高品質パッチでは高さ式の勾配によるGNGエッジ中点の接平面推定。隣接パッチの同じ位置での比較。

QRの6×6上三角行列に対するSVDでの条件検査。特異値比0.001を満たさない場合の全体SVD、0.00001を満たさない場合の未推定。正規方程式への置換なし。反復内の作業行列・ベクトルの再利用。

## 境界の3状態と非平面ノード

- 異なる原平面に由来するパッチ対を、`smooth_edges`・`sharp_edges`・`uncertain_edges` に分離。
- 低品質時の代表平面法線へのフォールバックを廃止。境界付近の各側のノード位置による追加フィット、それでも支持不足なら不明。
- 追加フィットはパッチ対の片側ごとに一度。`surface_model.max_boundary_fits` は既定32回、0で追加フィットなし。
- 面内支持共分散で正規化した二乗偏差16を超える境界位置は、過大な外挿として不明扱い。
- 不明境界は探索候補。新規統合には既存の距離・法線・曲率・退化モデル検査が必要。鋭い境界を経由した迂回統合は禁止のまま。
- 高品質な位置由来の境界接平面に対する、入力ノード法線による二重拒否の廃止。非平面ノードの新規抽出側接続ゲートは従来の法線判定。
- 新規抽出時は従来から、平面パッチと接続する適合非平面ノードを同一曲面へ統合。
- 追跡中にも、成立済みの追跡核から実GNGエッジで到達する適合非平面ノードを当該フレームへ付加。非平面ノード経由の接続も対象。
- 付加条件は、新規・維持の双方の距離／法線条件。既定ではエッジ長80 mm、表面距離4 mm、モデル法線角35度。曲面係数の再推定なし。
- 追加点は追跡参照集合へ登録せず、毎回の接続・形状再検査。逸脱した参照IDの抜け道となる再取込み、追加点だけによる追跡延命は不可。
- 表示時の元平面クラスタ数条件は変更なし。既定は新規曲面に2クラスタ。

基準法線の符号規約は、絶対値最大の世界座標成分を正方向へ統一。入力ノード法線の欠損・反転・乱れに依存しない局所推定。回転による符号規約の切替あり。形状比較には法線の向きの整合または曲率絶対値の使用。

有限点8個未満、線状支持、二次式の階数不足は未推定。円周上だけの点配置も階数不足の対象。二次式の係数6個に対する、残差評価用の余剰支持の確保。

## 品質・出力

- `/curved_surface_clusters/models` の `patches[].curvature.method`: `position_quadratic`。
- `position_rms_m`: 密度・Huber重み付きの高さ残差RMS、単位m。
- `fit_error`: 高さ残差の2倍を面内の小さい側の広がりで割った無次元の法線変化誤差目安。旧方式の実測法線残差とは異なる定義。
- `confidence`: 面内支持比、SVD特異値比、上記誤差による品質指標。確率・統計的信頼区間ではない値。
- `normal_scatter`: 入力ノード法線ではなく、二次曲面から推定した法線の重み付き二次モーメント。
- `tensor`・`kappa_per_m`・`directions_uv`: 実接平面に対する曲率、単位1/m。
- 既存の品質ゲート0.5、鋭い境界45度、点残差12 mm、パッチRMS 4 mmは維持。
- `fit_iter`・`has_svd_fallback`: 局所フィットの反復回数と全体SVD切替の有無。
- `boundary_ms`・`boundary_fit_num`: 境界判定時間と追加フィット回数。`curvature_ms` とは別計測。

最終版の追跡あり境界判定時間は平均0.080 ms。局所フィットは軽量化、一方で追加検査・探索候補増加により追跡なしの全体時間は増加。すべての条件での高速化ではない点に注意。

非平面ノード付加前の中間版は平均151.1ノード・2表示ID、付加後は129.9ノード・1表示ID。既存曲面の取り込みによる残りの候補構成の変化。付加に伴う表示点数の単調増加や、正解形状に対する精度向上の保証なし。

前回係数・基底による初期値再利用も試作比較。表示結果の改善なし、平均反復数は未使用3.93回・使用3.96回。性能向上を確認できないため、履歴管理と初期値再利用は本体から除去。今回の保存フレーム間では共通ノードの約98%が0.5 mm超の移動、所属と座標が完全一致する平面パッチは比較96組中0組。変更箇所だけの厳密な増分フィットは未採用。

## 残存課題

- 表示の途切れ改善。一方でID固定や同じ部位の連続表示の保証なし。
- 平面ID 6の全体局所品質は依然低く、一部境界の不明判定の残存。表示数は正解ラベルに対する精度ではない点に注意。
- 曲面の局所二次近似による有限幅誤差。カップ全周を単一の高さ式で表現する方式ではない点に注意。
- 外挿ガード内でも残る局所近似の不確かさ、追跡による小断片化、候補間の所属競合。明確な鋭い境界による追跡全体棄却は維持。
- 二次式を解けることと、ノイズ以下の微小曲率の識別可能性は別問題。

```bash

ctest --test-dir /ros2_ws/build/ais_gng -R '^test_(surface_model|plane_cluster_incremental|nonplane_component_extractor)$' --output-on-failure
```
