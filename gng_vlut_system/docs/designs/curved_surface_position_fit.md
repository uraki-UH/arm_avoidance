# 位置偏差による局所曲率推定

## 変更範囲

- `/curved_surface_clusters/markers` の前段となる局所曲率・境界接平面推定の位置ベース化。
- GNG学習・`plane_clusters`・`nonplane_components` の生成処理は変更なし。
- 既存の法線変化による局所推定の置換。新規ROS設定・外部ライブラリの追加なし。
- 候補全体のモデル推定・法線整合ゲート・追跡判定は維持。パイプライン全体からの法線除去ではない点に注意。

## 構築方法

1. パッチ内の有限ノード位置からPCA基準平面と面内座標の構築。
2. 面内広がりによる座標の正規化と、符号付き高さへの `h = au² + buv + cv² + du + ev + f` の当てはめ。
3. 面内セルの所属数による密度重みと、4回のHuber重み付きSVD。
4. 一次係数を含む傾斜補正と、実接平面の正規直交基底での曲率テンソル・主曲率算出。
5. 高品質パッチでは高さ式の勾配によるGNGエッジ中点の接平面推定。隣接パッチの同じ位置での比較。

基準法線の符号規約は、絶対値最大の世界座標成分を正方向へ統一。入力ノード法線の欠損・反転・乱れに依存しない局所推定。回転による符号規約の切替あり。形状比較には法線の向きの整合または曲率絶対値の使用。

有限点8個未満、線状支持、二次式の階数不足は未推定。円周上だけの点配置も階数不足の対象。二次式の係数6個に対する、残差評価用の余剰支持の確保。

## 品質・出力

- `/curved_surface_clusters/models` の `patches[].curvature.method`: `position_quadratic`。
- `position_rms_m`: 密度・Huber重み付きの高さ残差RMS、単位m。
- `fit_error`: 高さ残差の2倍を面内の小さい側の広がりで割った無次元の法線変化誤差目安。旧方式の実測法線残差とは異なる定義。
- `confidence`: 面内支持比、SVD特異値比、上記誤差による品質指標。確率・統計的信頼区間ではない値。
- `normal_scatter`: 入力ノード法線ではなく、二次曲面から推定した法線の重み付き二次モーメント。
- `tensor`・`kappa_per_m`・`directions_uv`: 実接平面に対する曲率、単位1/m。
- 既存の品質ゲート0.5、鋭い境界45度、点残差12 mm、パッチRMS 4 mmは維持。

## 残存課題

- 表示の途切れ改善。一方でID固定や同じ部位の連続表示の保証なし。
- 平面ID 6の局所品質は依然低く、代表平面法線へのフォールバックによる誤分断の残存。
- 曲面の局所二次近似による有限幅誤差。カップ全周を単一の高さ式で表現する方式ではない点に注意。
- 境界中点への外挿の不確かさ、追跡による小断片化、原平面所属の移動による全体棄却は未解消。
- 二次式を解けることと、ノイズ以下の微小曲率の識別可能性は別問題。

```bash

cmake --build /ros2_ws/build/ais_gng --target plane_cluster_incremental_node test_surface_model replay_surface_models -j2
ctest --test-dir /ros2_ws/build/ais_gng -R '^test_(surface_model|plane_cluster_incremental|nonplane_component_extractor)$' --output-on-failure
/ros2_ws/build/ais_gng/replay_surface_models /tmp/curved-diagnosis-J5NwFJ/observed.json
```

曲面テスト42件、平面・非平面抽出を含む3テスト実行単位の通過。位置だけの曲率、任意・欠損法線、回転・並進、密度差・局所12倍密集、外れ値、ノイズ、非有限点、階数不足、60度離れた円筒パッチの統合、本当の角の分離を含む検証。

比較元は `f29a949c` の5ソース・ヘッダを一時領域へ展開したもの。同じ `test/replay_surface_models.cpp` と旧ソースで生成した比較実行ファイルのコマンド。

```bash

```

保存データ・新旧JSONL・比較用旧ソースはコンテナ内 `/tmp/curved-diagnosis-J5NwFJ/` と `/tmp/position-curvature-V9wNH4/`。一時データのためGit管理外、別PCへのデータ持ち出しは別途必要。再評価入力は `models` 配列内に同一フレームの `map` と `planes` をROSメッセージの辞書形式で格納したJSON。
