# 姿勢領域ノードの表現力と評価指標の採否候補

目的: ノード数・メモリ・処理時間の予算内で、占有変化の少ない姿勢をまとめ、必要な姿勢と接続を欠落させない領域表現の比較。評価対象はロボット姿勢のGNGと追加の領域VLUTであり、環境点群を学習するGNGではない区別。

現状: 本体GNGは関節角度の点ノード。追加の領域ノードは連動一次制約・連動二次制約・比較用の独立角度箱。3D占有の大きさだけでは、関節領域の広さ・独自の被覆・手先姿勢・接続能力の評価として不十分。

## 0 改善の判定基準と同条件比較

以下のLong比較における`urdf_boxes`は、分割葉を独立ノードとした単層のURDF試作。配布版`vrm_cpp`の親領域・内部葉を保持した方式そのものの比較ではない区別。配布更新版の階層検証は本節末尾の別条件。

指標の候補一覧と、改善・採用の判定条件は別。以下は今回から固定した比較用の工学基準であり、論文の定理・実機安全規格・ユーザー承認済みの運用要求ではない区別。測定前の正本は[protocol.json](../../../benchmarks/gng_region_comparison/protocol.json)、条件と乱数種を対応させた[集計結果](../../../benchmarks/gng_region_comparison/results.json)。

### 判定の順序

1. 必須条件: 衝突参照への誤安全、安全参照への誤棄却、登録接続の遷移保証違反、種・保護姿勢の幾何学的欠落、差分カウンタ不一致の各0件。索引判定とfallback後の判定を別集計。反例0件だけでは全域の証明にならない制限。
2. 品質非劣化: 同一試行ごとに、索引付き担当領域へ入る必須姿勢数、層別の未見可行姿勢被覆、接続対・保護接続対の保持、安全区間の即時通過率、衝突検出率を比較。いずれかの低下を他指標で相殺しない基準。
3. 資源と利得: 品質非劣化を満たした候補について、領域数・保存配列・posting・訪問関係数の増加なし、総照会・照会p95・更新p95の各試行比1.05以内。中央値10 %以上の資源削減、または5 percentage points以上の被覆・接続等の増加を相対改善の暫定境界。利得方向は対応5試行すべてで一致、単純な重み付き合計なし。
4. 実用採用: 相対改善と別判定。既存の暫定目標は接続保持98 %、保護接続保持98 %、安全参照区間の要確認5 %。全可行姿勢・特殊手先姿勢・IK分枝の被覆、自己干渉モデルの整合、実行系への接続、動的停止・実機安全の各検証も別途必要。

10 %・5 percentage points・計時許容5 %は測定前に固定した工学上の暫定値。普遍的な優劣境界ではない値。差があるだけの候補はトレードオフ、局所カーネルの短縮は局所改善。未索引・暗黙残余への所属を索引被覆へ加算しない条件。索引なし対照は追加領域を持たないため、必須領域保持の合否対象外。

### 一次と二次の選択方針

暫定選択: 一次を基本、二次は選択肢として維持。上限128の既存比較では一次104ノード・3.28 s・要確認67.9 %、二次49ノード・5.10 s・94.7 %。二次による少ノード化と、安全確定率・総時間の改善は別。実使用ノード数の一致ではなく、共通上限による今回の実装・データだけの結果。

- MPC: 一次制約＋二次目的は通常QPの形。OSQPの対象も二次目的と線形制約。[公式の問題定義](https://osqp.org/docs/solver/)。今回の`linear_constraints(leaf_idx)`は選択葉の行列・上下限・状態。安全な葉の和集合は一般に非凸であり、親全体の凸包を安全領域として使用しない条件。二次領域も非線形MPCで利用可能であり、一律不適合ではない区別。[acadosの制約機能](https://docs.acados.org/features/)。MPC制御器への接続・実測は未実施。
- 所属・NN: 箱の所属は上下限比較、現在の連動一次の凸包所属はLP、二次は事前計算した逆行列による評価。一次一般の所属が常に軽いとは限らない区別。NNが最近傍探索の場合、中心の探索は領域型と独立。ニューラルネットの場合も入力表現・学習条件次第であり、一次／二次だけによる優劣の断定なし。NN連携の実測は未実施。

## 1 現在の表現

| 対象 | 保持する表現 | 区別 |
| --- | --- | --- |
| 本体GNG | 代表関節角度、隣接辺、従来のノードVLUT | 今回の追加領域による学習則の変更なし |
| `legacy`・`occupancy_cover`・`efficient` | `q=q0+Gλ, λ≥0, Σλ=1`の凸領域 | 関節ごとの独立区間ではなく、全関節の連動集合 |
| `quadratic_cover` | `q=c+Dz, ‖z‖≤1`と関節制限の共通部分 | 非対角の二次形式、低次元の生成部分空間にも対応 |
| `urdf_boxes` | `q_min ≤ q ≤ q_max`の直積 | 別形式の比較用。未索引の分割葉と索引付き領域の区別 |
| 領域の3D表現 | 対象リンク外接球と全領域の変位上界による占有包絡 | 全姿勢の真の占有和そのものとは限らない外包 |
| 接続 | 区間端点、領域の被覆フラグ、経由領域列 | 領域の近さや占有の重なりだけでは通過保証にならない条件 |
| 未被覆姿勢 | 暗黙残余の`unknown`、明示APIによる局所補完 | 明示被覆・探索グラフへの接続・到達可能性の証明とは別 |

既定バックエンドは`node_vlut`。領域方式は`region_vlut`の明示選択時のみ。`separate`では自己干渉などで不可行な姿勢を含む領域も許容し、実区間の内部離隔証明と環境照会を分離。外部`clear`だけで領域内の任意姿勢を許可する方式ではない仕様。

実装の正本: [構築・照会・現行評価](../../scripts/gng_region_vlut.py)、[選択・利用手順](../../README.md#3d占有に基づく領域ノード)。

### 集合と単位

| 記号 | 意味 | 保存データとの対応 |
| --- | --- | --- |
| `Q_i` | ノードiの連続関節角度領域 | 頂点または`generators`からの制約 |
| `F` | 関節制限・自己干渉・固定環境を満たす姿勢集合 | 独立の内部検査が必要な集合 |
| `B(q)` | 姿勢qでのロボット形状の占有 | 球モデル／メッシュ参照など、比較ごとに固定 |
| `S_i` | `Q_i`全体での`B(q)`の和集合 | 一般には厳密列挙なし。可行姿勢だけの和は別途`S_i^F`と表記 |
| `M_i` | 余裕を加える前の保守的な占有セル集合 | `occupied_ids`・`occupied_pointers` |
| `C_i` | 基準姿勢の占有セル集合 | `core_ids`。名前に反して全姿勢共通セルではない区別 |
| `O_i` | 離隔余裕・入力セル半径を含む照会用セル集合 | ボクセル→領域のpostingからの復元 |
| `K_i` | 領域内の全姿勢に対する衝突根拠となる内側セル | postingの`is_inner` |
| `h` | 共通格子の一辺 | m。セル体積和は`セル数×h³`、実物体積とは別 |

意図する関係は、モデル上の全域占有に対する`S_i ⊆ M_i`と、余裕付き照会に対する`O_i`の外包。参照形状・対象リンク・格子原点・幅・固定関節・余裕条件の一致が比較の前提。

関節空間の体積は、可動域幅で正規化した対象d軸での`μ_d(Q_i)`。数値次元がd未満の領域のd次元体積は0。一次領域の軸別最小・最大の積は外接箱体積であり、連動領域そのものの体積ではない区別。二次領域の未切断楕円体積も、関節制限との共通部分の体積とは別。

### ノードが担う量

- 総占有: `count(M_i)`。そのノードの外包量であり、姿勢の被覆率ではない量。
- 独自占有: `count(M_i \ union_{j≠i} M_j)`。他ノードにない3D外包セル数。
- 均等配分占有: 各セルの所属数を`m(v)`とした`sum_{v∈M_i} 1/m(v)`。全ノードの合計が占有和集合のセル数に一致する会計上の分担量。到達性や有用性の保証ではない量。
- 独自姿勢: `Q_i \ union_{j≠i} Q_j`の可行姿勢の測度／独立標本数。独自占有とは別の、姿勢欠落に直結する量。
- 接続貢献: ノード除去後に失われる可行姿勢対・保護タスク対・代替経路。上記の占有量とは別の役割。

独自占有0でも、異なる関節姿勢・手先向き・冗長解・接続を担う可能性あり。固定リンクによる正当な共通占有と、過大包絡や不要な二重表現を分ける必要性。`locate()`は最初の包含ノードだけを返すため、重複所属数・独自姿勢の集計には全所属の別確認が必要。

## 4 採否管理と測定条件

以下120項目は評価候補。今回の固定比較にはC01・C02・C03・G02・G03・S01・S04・E01・E07・P02・P03・L01・L05の一部を使用、適用範囲は第0節。比較対象以外の採否は未定。評価用の採用と、本体の学習目的・毎周期の新指標・APIへの採用は別扱い。

- 採否欄: 未定／比較対象／採用／見送り。変更時の記録は対象ID・用途・判断根拠・比較条件。IDは台帳用でありROS識別子ではない区別。
- 負荷「小」: 保存配列・既存カウンタからの集計。「中」: 限定近傍・標本・部分再評価。「大」: 密なFK／衝突参照、全対比較、反復計画・動力学試験。実時間の保証ではない分類。
- 比率: 分子・分母・母集団・参照未確定数・標本分布の保存。分母0／未計測は`null`などの無効値、0や達成扱いへの置換なし。
- 分布: 原則ノード別の最小・中央値・p95・最大と全体値。合計だけでは偏りや局所的な穴を隠す可能性。
- 評価層: 一様関節標本、実タスク分布、折畳み、可動域端、特異姿勢、狭隘部、手先姿勢、左右協調を別集計。高次元格子全列挙ではなく、固定予算の独立標本と反例探索を基本候補。
- 参照: 理想球での数値参照、より詳細な形状参照、実機測定を別層。選択用データと未使用検証データ、ロボットモデル、格子・余裕条件の分離。
- オンライン費用: 評価器を毎周期の処理へ直結しない方針。既存登録・posting・FK結果の再利用、重い参照はオフライン。

第2節の保存データ解析で算出済み: Q01・Q03・Q10、V01・V02・V04・V05・V06・V07・V09の一部。全所属姿勢・真の占有和・固定リンク内訳・task被覆・独立全域被覆は未計測。

## 5 先に比較したい組合せ

採用決定ではなく、低コストの診断から始める比較順の提案。

1. Q01・Q02・Q03・Q10: 全次元という分類と、実用的な幅・体積の分離。
2. V01・V03・V05・V06・V07・V09: 基準占有、追加包絡、独自分担、共有負担、強い棄却の成立性。
3. N01・N04・N05、C02・C03・C06、W03・W05: 占有が変わりにくい領域の広さ、独立可行姿勢と特殊手先姿勢・冗長分枝の欠落。
4. G02・G03・G05・G10: 幅のある接続口、保護task対、除去で壊れる接続。
5. S01・S02・S04、E01・E03、P03・P04: 三値の内訳、変更時の影響範囲、fallback込みの実費用。

安全・必須姿勢保持を先に判定し、その成立候補で被覆・接続・unknown・資源を比較する構成。全指標の単純な重み付き和への早期圧縮なし。未達の被覆をノード数減少や高速化だけで相殺しない扱い。

## 6 誤評価を避ける条件

- 占有の重なりだけでノード削除・統合を判断しない条件。独自姿勢・task・接続貢献との併用。
- 3D占有和、関節空間体積、手先の6次元被覆の相互代用なし。姿勢の異なる腕が同じ3D空間を使う場合も別扱い。
- `M_i`と密標本占有和の差は、未標本部分を含む量。真の余分な包絡量の過大推定になり得るため、標本密度・反例探索の併記。
- 端点占有の対称差セル数から、膨張距離や途中の掃引占有を直接上界化しない条件。端点が同一占有でも途中で大きく動く経路の可能性。
- 隣接領域の差分が両側の島になっても、それだけでは異常判定不可。屈曲、リンクの複数箇所移動、正当な冗長解、過大包絡、描画・登録誤りの切分け。
- 特異姿勢で手先変位が小さくても、肘など全身の占有不変とは限らない条件。逆に、占有がほぼ不変でも手先の向き・task能力の差を消さない条件。
- 通路・接続のための重複は必要な場合あり。平均重複率だけでの効率判定なし。占有セルの隣接連結成分数も、ロボット自身が複数形状であることと区別。
- 参照グラフ上での保持率、fallback込みの計画成功率、連続全空間の接続保証の区別。経路長比の改善時も消失した対数を併記。
- 分離領域の内部可行率と、証明済み実区間の安全性は別指標。形状・固定関節・余裕変更後の古い証明の持越しなし。
- 統計評価で反例0件でも全域証明への置換なし。信頼区間には独立性・標本分布・選択バイアス・試験回数の条件が必要。
- 観測点群と非交差という判定だけで、未観測・遮蔽空間も物理的に空いているとは限らない条件。観測・入力鮮度の前提と理想モデル上の証明範囲の併記。
- 動的停止・実機安全は静的関節域の安全性からの自動継承なし。速度・制動・遅延・追従誤差を含む別の検証条件。

## 8 採否変更時の記録

記録項目: 指標ID、用途、分子・分母、単位、参照条件、実装状態、測定費用、採否、判断根拠、比較した既存指標、再検討条件。

未定候補を増やす段階では定義と負荷区分まで。利用先が決まる前の独自スコア・仮の重み・未計算値の0埋めなし。採用時のみ実装・保存形式・テスト条件を確定し、現行指標の節と仕様へ反映。未採用を理由とする既存機能の削除なし。
