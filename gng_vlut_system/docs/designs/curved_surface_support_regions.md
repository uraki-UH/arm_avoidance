# 曲面モデルと観測支持領域の分離

## 修正内容

- 同じ曲面式に適合するだけで、離れた領域を同じクラスタとして保持する挙動の修正
- 新規抽出・追跡保持の双方に対する、曲面所属ノードの連続性検査
- 平面パッチ内部に複数の離れた領域がある場合も対象。パッチ所属・領域ID・Marker色の整合
- GNG学習・元の平面クラスタ・非平面成分の変更なし
- 角度／残差の厳格化ベンチマークとは独立した修正。実験方式の本番投入なし

## 支持領域の構築

1. 同一曲面所属ノード間の実GNGエッジによる連結成分の構築。既存の`max_link_length`による長さ制限
2. 未接続部分がある場合だけ、空間セルによる近傍探索
3. 物理距離・局所間隔・曲面接線・曲面途中の残差による小欠損の補完判定
4. 補完後も離れた成分の別領域化。支持数不足の小成分は`unknown`として曲面表示対象外

既に実エッジで連結した曲面では、空間近傍探索の省略。架空のGNGエッジやMarker線分の追加なし。

### 小欠損の条件

| 条件 | 内容 |
| --- | --- |
| 物理距離 | `min(max_support_gap, max_link_length)`による制限。既定20 mm |
| 局所間隔 | 端点ごとの最短の非零近傍距離。その小さい側に`max_support_spacing_ratio`を乗算。既定2.5倍 |
| 観測証拠 | いずれかの端点に`BOUNDARY_FREE_SPACE`がある場合の補完拒否 |
| 曲面接線 | モデル法線間30度、接続方向と各接平面のなす角30度の許容範囲 |
| 隙間内の形状 | 接続線分の1/4・1/2・3/4位置におけるモデル残差の検査。パッチRMS許容値の利用、既定4 mm |

入力法線の符号ではなく、曲面式の勾配からの接線判定。薄い曲面の表裏を、空間距離が近いだけで横断する接続の抑止。
完全に同じ位置の支持点は、長さのある隙間とは区別した同一領域扱い。

単一のUV座標系や面積の包絡矩形の導入なし。3次元近接・接線・モデル残差による局所近似。
途中3点の検査は形状の検査であり、ray castによる可視性・自由空間の確認ではない点に注意。
欠損・遮蔽の確定分類、過去の接続履歴を使った補完は未実装。

## 追跡IDと所属

- 最大の子領域は旧IDの継承。他の十分な支持を持つ子領域は新しい追跡ID
- 子領域の曲面係数は親の係数の継承。係数が同じでも領域・表示色は別管理
- 分割時は各子領域の現在ノードで参照集合を再構築。離れた旧領域を次フレームに再吸収する経路の除去
- 分割なしの場合は従来の参照集合を維持。単一外れ値の一時的な脱落・復帰の挙動を維持
- 保持曲面の表示資格は生成時の元平面数の継承。分割後の片側が1平面でも、十分な支持があれば表示
- `min_fit_nodes`未満の成分は曲面としての保持対象外。元ノード自体の削除なし
- 分割後のパッチごとの中心・曲率・残差の更新、パッチ間グラフの添字再構築
- 独立した永続モデルレジストリは未導入。同じ係数を持つ別regionによる分離

## 設定・診断情報

```yaml
surface_model.max_support_gap: 0.02
surface_model.max_support_spacing_ratio: 2.5
```

`max_support_gap: 0.0`は小欠損補完だけの無効化。離れた成分の分離は継続。
保持機能OFFでも、新規抽出に対する支持領域検査は継続。

`/curved_surface_clusters/models`への追加項目：

- `support_ms`：支持領域検査・必要な分割後更新の時間
- `support_split_num`：当該フレームで追加された成分数。表示対象外の小成分を含む値
- `support_gap_links`：小欠損補完で連結した組数。実GNGエッジの増加数ではない値
- `models[].support_parent_id`：分割直前の親領域ID。分割フレームのみの付与

## 検証

- 同一円筒面上の70 mm離れた2帯領域の分離・異なるID・後続3フレームのID維持
- 元パッチとノード所属の分割後整合、全ノードの重複なし被覆
- 10 mm間隔のエッジ欠損時のID保持
- 小欠損における自由空間証拠による補完拒否
- 近接する円筒反対側へのショートカット拒否
- 局所ノード間隔倍率による補完許可・拒否
- 支持不足成分の曲面表示抑止、無効パラメータの拒否
- 従来の外れ値復帰・配列並替え・追跡予算・表示色の回帰試験

曲面関連56テスト、平面クラスタ21テスト、非平面成分2テストの成功。

旧テストの「全エッジが消えても無条件に同一領域」という前提は廃止。小欠損保持を検証する4テストは軸方向間隔を40 mmから10 mmへ変更。大きな離隔の分離は別テストでの検証。

source install/setup.bash
