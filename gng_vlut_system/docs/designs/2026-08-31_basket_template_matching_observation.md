# basket GNGテンプレート照合の実測メモ

## 位置付け

- 状態: `basket`の遮蔽なし点群へZY並進とyaw回転を与え、CPU GNGで学習した環境側GNGとの比較記録
- 対象テンプレート: `/datasets/basket_gng_template.json.gz`
- 環境入力: `/semantic_points`、`/topological_map`、`/plane_clusters`
- 非目的: 平行移動レジストレーションの仕様化

位置中心合わせは、テンプレートと環境GNGが同一形状を表すかを確認する診断専用処理とする。
実行時照合は平行移動を探索せず、yawと並進不変な局所特徴を使う。

## 入力規模

| 項目 | テンプレート | 環境 |
|---|---:|---:|
| 入力点数 | - | 4,200 |
| GNG node数 | 279 | 392 |
| GNG edge数 | 665 | 917 |
| 平面クラスタ数 | 5 | 5 |

環境側のnode数が多く、最大edge長はテンプレートの約29 mmに対して約178 mmとなる。
環境側には余剰node、別構造への接続、または外れedgeが含まれる前提で扱う。

## yawと幾何診断

位置中心合わせ後のyaw走査では、最良yawは46度だった。
平面クラスタの法線・extent対応では最良yawは47度、法線だけのGNG照合では10度刻みで50度だった。

| 指標 | 実測値 |
|---|---:|
| 対称Chamfer距離 | 6.476 mm |
| template -> environment最近傍距離中央値 | 6.096 mm |
| environment -> template最近傍距離中央値 | 6.581 mm |
| 空間近傍で対応したtemplate edge | 342 / 665 = 51.4% |
| 対応edge方向差中央値 | 17.8度 |
| 対応edge長比中央値 | 0.912 |
| 対応edgeの絶対Z差分誤差中央値 | 1.302 mm |

GNGのnode密度と接続は変化しているが、形状と局所edge構造は対応している。

## 法線

GNG node法線には符号反転がある。

| 指標 | 実測値 |
|---|---:|
| 符号付き法線角度中央値 | 38.0度 |
| 符号付き法線角度90パーセンタイル | 174.6度 |
| 符号不変法線角度中央値 | 10.8度 |
| 符号反転率 | 40.1% |

法線は表裏を区別しない方向特徴として扱う。比較式は次とする。

```text
normal_angle = acos(abs(dot(normal_template, normal_environment)))
```

符号不変化後の現行照合器では、対応node率は64.9%から99.3%へ増加した。
ただしedge一致率は約6.7%のままであり、node単体の貪欲対応だけでは局所グラフ対応を確定できない。

## 平面クラスタ

平面クラスタは最も安定したyaw推定・上位構造指標だった。
符号不変法線、extent、平面性を使った対応では5平面全てが対応した。

| template平面 | environment平面 | 法線角度 | extent比 |
|---:|---:|---:|---|
| 1 | 3 | 0.12度 | 0.645, 0.917 |
| 2 | 245 | 1.18度 | 1.163, 1.183 |
| 3 | 4 | 0.65度 | 1.206, 1.131 |
| 4 | 1 | 2.32度 | 0.981, 1.054 |
| 5 | 2 | 2.42度 | 1.107, 1.004 |

底面の短辺extent比は0.645まで縮むため、extentと面積は厳密一致ではなく片側欠損を許容する
ファジー評価とする。

平面で使う候補指標は以下とする。

- 符号不変法線角度
- extentのソート済み比、縦横比、面積相当値
- `planarity`、`residual_ratio`、`local_spacing`による平面信頼度
- 平面対ごとの絶対法線内積、重心間距離、重心差のZ成分
- 平面間のGNG接続関係

## winner残差共分散

`winner_point_covariance`は、勝者nodeに対する入力誤差
`input_point - winner_node_position`の共分散である。所属点群そのものの座標分散ではない。

| 指標 | 実測値 |
|---|---:|
| winner残差サンプル数中央値 | 1,027 |
| 共分散固有値相対差中央値 | 0.295 |
| 共分散固有値相対差90パーセンタイル | 0.668 |

共分散は固有値比と局所edge長の二乗による正規化値を補助ファジー特徴として使う。
現在の保存形式は共分散のみで、残差平均は保存していない。

## 指標の優先度

1. 平面クラスタ集合による符号不変法線とyaw
2. 平面間の相対構造
3. 局所edge長列、edge長比、edgeのZ差分
4. 隣接node間の符号不変法線内積
5. winner残差共分散の固有値比と正規化値
6. `rho`とnode次数のファジー補助評価

`rho`の相対差中央値は0.337、90パーセンタイルは0.809であり、単独の採否条件には使わない。
`winner_point_count`は入力密度と学習時間に依存するため、形状特徴ではなく観測信頼度として扱う。

## 現行照合器の課題

- 平面クラスタをyaw候補生成と対応seedへ未使用
- edge長とedgeベクトルをnode対応の生成へ未使用
- 共分散固有値をscoreへ未使用
- node単体の貪欲対応によりedge構造一致が低下
- 反証評価は局所グラフ対応を改善した後段で適用する必要

次段階では、平面対応でyaw候補を絞り、平面に属するnodeをseedとして局所edge構造を伝播照合する。
