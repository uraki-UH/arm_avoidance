# 密度・表現形式の異なるGNG間の部分形状照合：問題設定

更新日: 2026-09-09。前提の整理。手法・実装順・数値目標は未確定。

## 目的

テンプレートと実点群由来のGNGにおける、**一緒に観測された部位の形状・相対配置の整合性**の照合。
グラフ構造の一致ではなく、同じ物体としての説明可能性の評価。

## 確認済みの前提

- 局所的なノード密度差の許容。次数・ノード数・エッジ接続の一致は非必須。
- 同一部位における「面・三角形群」「単一エッジ」「ノードと局所誤差分散」の表現差の許容。
  メッシュは非必須。密度由来の表現変化と、物理形状の不一致との区別。
- 遮蔽下の部分一致が対象。全ノード対応・テンプレート全体の観測は非必須。
- 平面対応による探索起点の許容。平面対応の欠落だけによる棄却は不可。
- テンプレートと実物体は基本的に同じ実寸。スケールの基準倍率は1。
- 基準倍率1付近の設定可能なスケール幅とroll・pitch許容度によるファジー評価。任意のサイズ違いへの対応は基本対象外。
- yaw全周360度での同一テンプレート共用。全角度総当たりは非必須。
- 複数テンプレートに対する、観測部分の証拠からの候補逆引きの検討。

## 入力と照合の考え方（設計案）

基本入力は座標系・単位の分かるノード位置とエッジ。法線・分散・平面・観測方向は利用可能な範囲での活用。
depth・元レイは追加の観測証拠。必須化は未決。背景・誤接続・不完全なテンプレートも想定内。

- **部位どうしの多対多対応**：密な20ノードの面と疎な3ノード・2エッジとの対応も許容。
  比較範囲への実空間の広がりの反映。同じ観測領域の重複加点の抑制。
- **共通の変換**：全対応部位に共通の姿勢・倍率。部位ごとの自由な変形は対象外。
  同じ実寸での部位間距離・幅・高さの比較。密度差や部分欠損を物体の縮小とみなす倍率補正は不可。
  個別エッジ長ではなく部位の実空間範囲を基準とし、全体サイズの正規化による実寸情報の消去は対象外。
- **分散の意味**：入力座標の広がり、勝者残差、位置推定誤差、個体差の区別。
  集計条件の確認。残差分散から物体幅への無条件な読み替えは不可。
- **共起の意味**：形状・配置の整合、同時観測、共視性の区別。
  エッジ接続や観測方向範囲の重なりだけによる共視性の証明は不可。

## 判定の原則

| 証拠 | 扱い |
| --- | --- |
| 観測された部位の形状・配置が整合 | 肯定証拠 |
| 低密度・遮蔽・視野外・深度欠損による欠落 | 不明。欠落だけによる棄却は不可 |
| 信頼できる形状または自由空間との矛盾 | 誤差と許容変換を考慮した反証 |
| 複数テンプレートが同じ観測を説明可能 | 複数仮説の保留 |

自由空間の反証には実測レイ等と位置・姿勢が必要。エッジ線分や分散の裾と実測表面との区別。
例：低いコップに高いコップを仮定した際、余分な上部を通って背景まで測距できれば反証の候補。
その領域が遮蔽・深度欠損なら保留。一つの姿勢での矛盾や検索予算による候補落ちは、テンプレート全体の棄却とは別。
現行の[観測方向範囲](../../../ais_gng_cpu/docs/observation_support.md)には自由空間・共視性・履歴の保持なし。

## 評価と未決事項

評価対象は、密度差と面→エッジ化、平面対応の有無、部分遮蔽、部位の配置違い、設定した姿勢・スケールの境界、
高さ違いのコップ、未登録・対称物体、テンプレート数の増加。
密度条件はGNG再学習、遮蔽条件は可視性を考慮した生成または実測による評価。単純な点削除との区別。
誤棄却率・誤認識率・正解候補残存率・保留率・処理時間・メモリの併記。全保留だけでの成功判定は不可。

未決事項は次の4点。

1. 同じ実寸を基本とした、同一個体・同型製品の形状差の許容範囲。
2. グラフのみで必要な出力と、局所統計・depth等の利用条件。
3. 並進・姿勢の推定／出力範囲、回転規約、基準倍率1付近のスケール許容幅とファジー評価関数。
4. 時系列統合の範囲と、精度・候補数・時間・メモリ予算。
