# 変更量主体の平面所属更新（2026-09-28、段階的試作）

## 要約

推奨は「幾何統計の差分更新」と「所属判定の必要性判定」の分離。値の微小変化を一律に捨てる方式ではない。
統計差分・保持証明・境界候補限定・移籍と新規生成候補の周期分散を実装。下記は全体の設計案であり、実装済み範囲・採否は[計測記録](../../../benchmarks/plane_consistency_20260924/PROFILE.md)を参照。
目標は2万ノードの代表交差点入力で5 ms以下と、定常時の総ノード数への依存削減。実現済みの性能ではない。
[先行計測](../../../benchmarks/plane_consistency_20260924/PROFILE.md)は9.818 ms。入力準備2.690＋新規生成1.843だけで4.533 msあり、表示エッジ削除だけでは不足。
同入力の位置変更43.47%・法線変更70.66%から、全ビット変化を高価な再判定へ直結する差分化は不十分。
初回・全点変化・大規模分裂は全体処理を許容。入力を捨てて5 msに見せる打切りや、無断の所属更新遅延は対象外。
9月28日の追加依頼により段階的な所属獲得を許容。候補をIDで巡回分散し、逸脱判定と未所属点の吸収は毎入力。
初回は毎回更新が既定、最新作業開始時点の手元の5周期を維持。幾何入力・EMA・統計を間引く方式ではない。
追加の所属1パス方式は実装・比較済みで既定OFF。固定モデルの判定後に再推定・逸脱再確認を追加した場合の短縮は小さく、面数も増加。
面外根拠数の事前走査も比較したが、全点走査の追加により遅くなり撤去。次案は新たな一律走査を前提としないこと。[判断](../reject.md)。

### 1. データと責務

- GNGグラフの座標・法線・接続を正本とし、平面層は世代付きノードキー→平面IDと統計・判定キャッシュを保持。
- 平面IDとunknown/human/car等は独立。ノード位置・エッジをクラスタごとに複製した別グラフは不要。
- 既存`GngMapDelta`に不足する法線・rhoの更新も通知。位置変更の隣接への影響、外部ラベル更新、パラメータ変更を含む依存関係の明文化が必要。
- コールバック中の借用グラフ参照＋変更キー列を基本とし、全ROSメッセージからの差分探索をCPU直結経路の必須処理にしない。
- 世代変更、初期化、フレーム欠落、順序逆転、TF／座標系変更は差分を盲信せず再同期。旧／新の値が必要な統計更新にはノード単位の必要最小限の履歴を保持。

### 2. 平面を小さな内部計算単位で保持

- 巨大平面の内部を、近接する数十～百程度のノードを参照する小ブロックに分割。個数は設計例であり既定値未定。
- ブロックは別の平面クラスタではない。外部ID、統合・分断の単位、平面の意味を変更せず、所属ノードを減らさない。
- 各ブロックに点数、局所原点からの一次和・二次モーメント、局所間隔和、保守的な範囲、判定余裕を保持。
- ノードの移動は旧寄与の除去＋新寄与の追加。所属変更は移動元・移動先へ反映。更新ブロックの統計差分を親平面へ集約し、巨大平面の全点を再累積しない。
- 平面方程式の更新は所属保守の同期フェーズ境界。ノード1点ごとの固有値分解や、走査途中の即時モデル変更は避ける。
- 法線和の順序依存は十分統計へそのまま移植できない。既存面は前回法線への符号整列、新規面は種の参照方向で初期化する候補。浮動小数点のビット一致は保証せず、判定・品質を別途検証。
- 巨大座標での桁落ちは局所原点、中心化モーメント、必要時のブロック再集計で対処。誤差蓄積の判定・再集計頻度は要評価。
- 新しい生点群格納やFVGは不要。既存ノードへの参照と統計だけを追加。ブロックの再編成コストも計測対象。

### 3. 判定余裕による再評価の省略

平面の微小な回転でも、遠方ノードが外れ値になる可能性があるため、「平面が少し変わったので無視」は不可。
あるブロックの原点をo、全点の距離上限をR、単位法線をn、平面式を`n·(p-o)+b`とする。
点が不変なら符号付き距離の変化上限は `R * ||n_new - n_ref|| + |b_new - b_ref|`。
前回確認時の各点の保持距離条件までの余裕の最小値が、この上限より大きければ、距離条件の全点再評価を省略可能。
法線整合も、点法線不変なら内積変化の上限`||n_new - n_ref||`で独立に確認。両条件を保証できる場合だけ保持判定を省略。

- 比較基準は前フレームではなく**最後に正しく確認した状態**。微小変化の蓄積によるゆっくりした逸脱を見逃さない。
- ノード位置・法線・局所間隔の変化、所属の出入りは該当キャッシュを更新／失効。古い余裕値の無条件再利用は禁止。
- 保証不能は「外れ値」ではなく「再評価が必要」。該当ブロック内の点を既存条件で検査。
- この上限は保持条件用。境界の移籍・未所属点の取り込み・統合にもそのまま適用できると扱わない。
- 移籍候補は変更接続・境界・未所属点の作業リスト。自平面／相手平面の変化、供給元の点数保護条件の変化でも再評価。同期更新と同点の選択規則を明示。
- ブロック一律走査を残す場合もO(N/ブロック容量)の依存は残る。まず低い定数の保守的判定を試し、複雑な優先度キューは効果を確認してから検討。

### 4. 新規生成・分断・統合を必要な箇所へ限定

- 新規平面は全未所属点の再ソート・再探索を毎回行わず、追加点・解放点・条件の変わった未所属領域を候補にする。
- 失敗した探索の再利用は、判定に使った接続・支持点・幾何・隣接所属が不変と確認できる場合から開始。原因を記録しない永久除外や単純な待ち時間は不可。
- 分断は削除された証明木エッジ・所属削除の影響成分を再探索。現在既にある証明木再利用を拡張し、単なる接続消失では分割しない条件を維持。
- IDキーの連結証明を実装済み。無関係な点の増減・配列順変更では失効せず、所属集合・直前フレーム・木エッジを確認。世代付き変更通知による検査省略は未実装。
- 非連結のまま保持する成分もキャッシュし、接続不変なら連結探索を反復しない。方向根拠は幾何変化に応じて更新。
- 統合は境界接続表の差分更新と、両平面のモデル／接触条件が変わった対の評価。連鎖統合の統計更新と小面・段差保護を維持。
- 法線EMAの収束、連続確認、孤立猶予は入力差分がなくても進む。処理回数ではなく元フレームに対応した更新。現行EMAを無条件に飛ばさない。

### 5. 計算と表示の分離

- 9月28日の追加依頼でエッジ座標複製と平面MarkerArrayを既定OFF化。幾何と所属の出力は維持。共有頂点の差分APIとは別の、不要な生成・複製の省略。
- 計算側の出力は平面ID・所属差分・必要な平面統計。OBB・文字・表示エッジの生成をクラスタ判定の必須経路から外す。
- 表示は元グラフの共有頂点と所属を参照。座標だけの変更ではエッジ所属を再構築せず、接続または所属変更時に表示用参照を更新。
- Viewerは表示だけを担当し、点の編集・座標変換をフロントへ移す案ではない。既存バックエンドの責務分割を維持。
- 全量出力・RVizマーカーは互換アダプターとして必要時に生成。差分だけでは新規購読・再接続に対応できないため、世代・順序と初期スナップショットが必要。
- 表示が未購読でも、把持・曲面・非平面抽出用の所属は更新。表示負荷を別ノードへ移すだけの見かけ上の高速化を避け、システム全体も計測。

## 条件・検証

第1段階では平面統計の差分更新＋ブロック保持判定を試作。その後の境界候補・周期分散の仕様は[設定説明](../releases/2026-09-28_plane_delta_prototype.md)を参照。
統計は親平面へ直接加減算。保持ブロックは連続64ノードの同一所属区間のみで、空間近接による再編成は未実装。
差分の発見は全入力比較のためO(N)。世代付き変更通知の直接受入れ・欠落検出・表示経路共有は未実装。
次に永続隣接・新規生成作業リスト・分断キャッシュを接続し、最後に表示・通信の差分経路を適用。完成前の方式を現行仕様とは扱わない。
固定変更数で総ノード数を5千・2万・5万へ変更する試験と、変更率を変える試験の両方が必要。静止入力だけでの高速化を採用根拠にしない。
品質は、段差・交差面・巨大平面内の小面・遅い逸脱・ノード世代再利用・削除／再接続・欠落／逆行で確認。所属、平面残差、法線差、ID安定性、追従遅延を評価。
速度は初回／定常を分離し、平均・p95・最大、変更通知のGNG追加費用、表示・シリアライズを含む全体時間とメモリを報告。代表入力5 ms以下は未検証。
変更量が大きい場合や保証不能な場合の全体再評価は許容。常時5 msの上限保証には処理遅延・品質との別の合意が必要。
