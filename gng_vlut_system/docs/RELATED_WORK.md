## 1. Steffen et al. 2022 — Reactive Neural Path Planning in a Condensed Configuration Space

- arXiv:2207.03959 / Lea Steffen, Tobias Weyer, Stefan Ulbrich, Arne Roennau, Rüdiger Dillmann (FZI Karlsruhe)

**最も近い先行研究。** 中核構成が本プロジェクトとほぼ同じ。

### 手法

1. GNG(または γ-SOM)を pick&place 軌道で学習し、縮約 C空間を得る。ニューロン = 関節配置 = 海馬の場所細胞に相当する認知地図
2. 双方向ルックアップテーブルを順運動学で事前構築(タスク空間ボクセル ↔ 関節配置)
3. 視覚(GPU-Voxels + RealSense×4)で障害物をボクセル化し、該当ニューロンをブロック
4. グラフ探索(Wavefront vs Dijkstra)で経路を求め、NURBS で平滑化
5. 0.3秒ごとに再計画。3条件のいずれかを満たすときだけ新経路を採用
6. UR3e(6自由度)実機で検証。MoveIt2 の PRM/RRT/RRTConnect と定量比較

### 実測値(Table I, II)

| 構成 | 時間 |
|---|---|
| GNG + Dijkstra(平滑化なし) | 13ms |
| GNG + Dijkstra + NURBS平滑化 | 37ms |
| γ-SOM + Wavefront | 7ms |
| PRM | 115ms |
| RRT | 2876ms |
| RRTConnect | 23ms |

ニューロン数10,000。平滑化がパイプライン中で最も重いと明記。

注意: Abstract は「0.02秒で再計画」と書いているが Table I の GNG+平滑化は 0.037秒で一致しない。引用には Table I の値を使う。

### 本プロジェクトとの差分

**共通**: GNG による縮約C空間、ボクセル↔配置のLUT、位相地図上のグラフ探索、ROS 2。GNG が SOM より優れるという結論も同じ(SOM は剛な2D構造ゆえ高次元C空間と位相不整合を起こす)。

**本プロジェクトのみ**:
- 把持そのものを扱う(論文は目標配置が所与。pick&place は学習データとしてのみ使用)
- 可操作性による候補評価(論文に評価指標の概念がない)
- 双腕(論文は6自由度単腕)
- 自己認識フィルタ
- 候補姿勢と GNG ノードの多対多
- 学習データが URDF 由来(論文はタスク特化の軌道1230本 + 手動教示)

**論文のみ**:
- 動的障害物へのリアクティブ再計画の実機実証
- サンプルベースプランナとの定量比較
- NURBS 平滑化と再計画の受理基準3条件
- γ-SOM との比較検証

### 論文が明記している限界

1. **学習データ依存** — 学習した部分空間しかカバーしない。タスク特化軌道で学習しているため、想定外の動作は計画できない。本プロジェクトは URDF 由来なので構造的に回避している可能性がある(要実証)
2. **補間区間の無衝突が保証されない** — ノード間の関節角跳躍が最小障害物サイズを超えると、補間軌道の無衝突を保証できない
3. **距離尺度がない** — 障害物との距離を持たないため、後退や一定距離維持のようなタスクが不可能
4. **経路解像度とメモリのトレードオフ** — ニューロン数を増やせば解像度は上がるが SONN と LUT のメモリが増える
5. **cluttered scenes / narrow passages が未評価** — 「理論上は影響を受けにくいはずだが評価していない」と明記

### 引用する場面

- 手法の直接の比較対象として(Related Work、実験の比較相手)
- 限界2と3は本プロジェクトの貢献の起点。「先行研究が保証できないと明記した部分を保証付きにした」という形で使う
- 限界5はゴミ処理場という cluttered 環境での実証が貢献になる根拠

## 2. Reachability Map / Capability Map

- Zacharias et al. ほか。Springer "Reachability and Capability Analysis for Manipulation Tasks"

### 手法

事前計算した到達可能な手先姿勢を3次元グリッドに格納する。各セルについて一様サンプリングした姿勢に対する IK 成功率(自己干渉チェック込み)を求め、その比率をセルの値とする。到達性データに「その領域の良さ」を定量化する指標を加えたものが capability map。
得なくていいよ
用途はベース配置、把持姿勢選定、ワークスペース解析。

### 本プロジェクトとの差分

**索引が手先姿勢である点が決定的に違う。**

| | capability map | 本プロジェクト |
|---|---|---|
| 問い | どこに手が届くか、どの程度良い姿勢か | 動的障害物下でどう安全に動くか |
| 索引 | 手先姿勢 | 全身占有 |
| 構造 | ルックアップ | グラフ(位相接続あり) |
| 冗長性 | IK成功率というスカラーに潰れる | 占有で区別され保持される |
| 障害物 | 静的。事前計算物 | 実行時にノードをブロック |
| 衝突保証 | なし | 3値論理で保証 |

同じ手先姿勢を実現する肘位置違いの姿勢群は capability map では同一セルに入るが、占有は全く異なる。cluttered 環境の衝突回避ではこの区別が本質。**自己運動多様体こそが占有を変える次元**であり、そこが捨てられている。

また位相接続を持たないためグラフ探索ができず、経路計画には使えない。

### 引用する場面

- 「タスク空間を離散化して各セルを実現する姿勢を求める」という**構成手順**の先行例として。サンプリングバイアス回避策の出典
- 差分として「手先姿勢索引では冗長性が潰れる」ことを述べる場面

## 3. RichMap (2026)

- arXiv:2604.06778

### 手法(調査範囲)

reachability map のグリッド構造を精緻化しつつ構造的柔軟性を保つ。S² / SO(3) 上の理論的な容量限界を用いて被覆の厳密性を確保する。予測精度 >98%、偽陽性 1〜2%、大量バッチクエリ ~15μs/query。非同期パイプラインで構築を高速化。MMD によるワークスペース類似度の定量化、拡散方策の転移への応用も扱う。

### 本プロジェクトとの差分

離散化の粒度と被覆の厳密性を扱っている点で、本プロジェクトの「被覆半径の上界保証」と議論が重なる可能性がある。

**要確認**: Abstract 範囲では冗長自由度・自己運動多様体・全身占有の扱いが不明。本文を読んで、被覆保証の定式化が本プロジェクトの主張と competing かどうか判断する必要がある。

### 引用する場面

- 被覆の厳密性を扱う近年の研究として。ただし competing かどうかは本文確認後に判断

## 4. Reachable Volumes (RV)

- McMahon, Thomas, Amato. IJRR 2018 (doi:10.1177/0278364918779555)、IEEE 2014
- Parasol Lab (Texas A&M / Illinois)

### 手法

ロボットの各関節・手先が制約を満たしつつ到達できる領域を幾何的に表現したもの。reachable distance の概念を一般化し、リンク機構・閉ループ・木構造ロボット、直動/球面/平面関節に適用できるようにした。

**制約を満たすサンプルを生成する**ために使う。閉ループ拘束のような制約は従来のサンプリング法では有効な配置を作ること自体が難しいが、RV はこれを効率的に解く。非制約問題では O(1)、多くの制約問題でも O(1) の計算量。RV サンプルは自己干渉で無効になりにくい。多ループ・木構造で1000自由度以上の問題を解いている。

### 本プロジェクトとの差分

**全身のリンクを扱う点は近いが、測っている量が違う。**

- RV = 各関節が**どこに到達できるか**(運動学的制約の充足)
- 本プロジェクト = 姿勢間で**占有がどれだけ変化するか**(配置の計量、および衝突保証)

RV が扱うのは主に**運動学的制約(閉ループなど)と自己干渉**であり、環境障害物は通常のプランナ側の衝突判定に委ねられる。占有集合を計量として使う発想ではない。

したがって「全身を考慮する」という点での最近接先行研究ではあるが、主張は競合しない。

### 引用する場面

- 全身のリンクを考慮する先行研究として Related Work に置く
- 「手先だけでなく全身を扱う必要性」の論拠として引用できる

## 5. Workspace Importance Sampling (WIS)

- H. Kurniawati, D. Hsu. IROS 2004

### 手法

1. 障害物に occupied されていないワークスペース `W'` の境界上に点をサンプリングし、**四面体分割**する
2. 各四面体 `t` に重要度 `h(t)` を割り当てる。`h(t)` は t の平均高さ(局所的な「幅」の推定値)。境界面を持つ場合はその面に対応する高さのみ平均する
3. `h(t)` が小さい = 狭隘通路にある可能性が高い
4. 四面体を一様ランダムに選ぶ(狭隘通路は単位体積あたりの四面体数が多いので、自然に密になる)
5. 選んだ四面体内で最大 `n_t` 回サンプリングして無衝突配置を探す。`n_t = ln(1-α) / ln(1 - h(t)/h_total)`
6. 多関節ロボットの場合、四面体から手首点の位置をサンプリングし、**IK を解いて** `q_τ` を得る。IK 解が多数/無限なら数個をランダムに採る。手首姿勢 `q_θ` は一様サンプリング

### 論文が明記している限界

1. **ロボットの幾何を無視している** — ワークスペース情報だけで狭隘通路を特定するため偽陽性が出る。重要度が高くてもロボットが通れないほど狭い領域があり、そこを密にサンプリングするのは逆効果
2. ワークスペース情報を配置の**位置成分にしか使っていない**

### 本プロジェクトとの差分

**限界1が本プロジェクトの出発点そのもの。** WIS が「無視している」と明記したロボット幾何を、占有集合として計量の中心に据えるのが本プロジェクトの立場。

| | WIS | 本プロジェクト |
|---|---|---|
| 使う幾何 | 自由ワークスペース(障害物依存) | ロボット占有(障害物非依存) |
| 目的 | 狭隘通路へのサンプリング偏重 | 占有計量での一様被覆 |
| ロボット幾何 | **無視(論文が明記)** | 中心的に使用 |
| 障害物が変わったら | 四面体分割をやり直し | オフライン構造は不変。実行時にノードをブロック |
| 逆写像 | IK(多価。数個をランダム採用) | FK で構成すれば不要 |

### 引用する場面

- **重要**: 「ワークスペース情報で C空間サンプリングを誘導する」という発想自体は既存であることを示す出典。この点を新規性として主張してはいけない
- 差分として「WIS はロボット幾何を無視すると自ら述べている。本手法は占有を計量に据えることでこれを解消する」と書く場面

## 新規性の置き場所(現時点の整理)

上記を踏まえると、主張できるのは以下。

1. 計量を**占有集合そのもの**で定義する(手先姿勢ではなく全身。capability map と WIS の双方に無い)
2. 膨張 + 3値論理による**補間区間の無衝突保証**(Steffen et al. が保証できないと明記した部分)
3. 膨張量のボクセル埋め込みによる局所最適化
4. VLUT 逆引きによる**動的障害物への対応**(capability map / RV / WIS はいずれも静的または非対応)
5. cluttered 環境(ゴミ処理場)での実証(Steffen et al. が未評価と明記)

主張してはいけないもの:

- ワークスペース情報でサンプリングを誘導すること自体(WIS 2004)
- タスク空間を離散化して姿勢を対応づけること自体(capability map)
- 全身のリンクを考慮すること自体(Reachable Volumes)
