# 車両モデルの位置合わせと曖昧な分類

## 1. 要約

交差点の選択クラスタへ4種類の車両表面モデルを位置合わせし、候補・適合度・未対応部分を表示。
「車両モデルへの適合」と「車種の絞り込み」を分離し、観測不足や候補の競合時は判定保留。
今回はGNGノードへの幾何照合。学習済み車両認識器・連続追跡・生LiDAR点群照合ではない。

`/topological_map` のBBox・ホバー選択・選択有効化ボタンは、ユーザー指示により撤去。
旧ON設定でも表示・選択を無効化。現在、このトピックから独立ビューを開く操作導線はない。
照合RPCと、他の選択可能なcluster/component独立ビューの「車モデルを比較」は保持。

起動済みの旧Viewerには、同じDocker内で追加ノードを起動:

```bash
source /ros2_ws/install/setup.bash
ros2 run topo_fuzzy_viewer viewer_vehicle_registration_node.py
```

次回から `ros2 launch topo_fuzzy_viewer viewer_stack.launch.py` に含まれるため、追加起動は不要。
同じROSドメインでの照合ノードの重複起動は不可。

| 候補 | モデル |
| --- | --- |
| 乗用車・セダン | DrivAerML run_1の実表面、4.70 × 2.02 × 1.51 m |
| 軽自動車相当・背高 | 3.35 × 1.45 × 1.75 mの簡易形状 |
| 乗用車・バン | 4.60 × 1.80 × 1.90 mの簡易形状 |
| 箱型トラック | 5.40 × 1.90 × 2.70 mの簡易形状 |

簡易形状は代表寸法の仮定。実車種や法的な車両区分の同定ではない。

## 2. 条件・検証

| 指標・表示 | 意味 |
| --- | --- |
| 観測一致率 | モデル表面から一致距離内にある観測ノードの割合。既定0.25 m |
| モデル支持率・緑 | 観測ノードから支持距離内にあるモデル表面サンプルの割合。既定0.35 m |
| 未対応率・黄 | 1 − モデル支持率。遮蔽・疎な観測・形状差を含む欠損候補。破損率ではない |
| 一致点RMS | 一致ノードからモデル表面サンプルへの距離のRMS、m。一致なしは無効値 |
| 適合度 | 観測一致率 × exp(−RMS / 一致距離)。0〜1、認識確率ではない |
| 赤 | 一致距離外の観測ノード |

候補順位は適合度 × (0.65 + 0.35 × モデル支持率)。未観測面を強い不一致とは扱わない。
車両適合の一次判定は一致率0.65・支持率0.18・観測長手1.5 m・観測高さ0.5 mを条件とする仮置き。
分類候補の絞り込みは支持率0.35と上位2候補の順位スコア差0.08。しきい値の実データ校正は未実施。

- Z上向き・車体直立を仮定したYaw＋XYZの位置合わせ。モデル寸法固定、前後方向は未確定。
- 各3500表面点、16方向と位置ずれからの多初期値探索。最適化は最大500ノード、最終評価は選択全ノード。
- 12〜20000ノード・範囲30 mの入力制限。座標系不一致・非有限値・線状のみの観測はエラー。
- 既知姿勢の欠損セダン、箱型トラック、非車両平面、外れ値、入力検証の5テスト成功。
- 実交差点の33ノードでは一致率100%でもモデル支持13.6%のため判定保留。正解車種の精度評価は未実施。
- 4モデル比較は取得時の実クラスタで約0.8秒、316ノードの合成欠損観測で約3.1秒。GNG各フレームへの追加計算なし。
