# 引継ぎ事項 — 送付版 1.0.0

## 送付物

標準・Longのローカルシミュレータに、ソース・データ・説明書・再生成ツール・第三者条件をまとめています。開発PC固有の絶対パス、IP/ユーザー名、認証情報、開発用SSHランチャー、実行ログ、利用者が保存したポーズ/点群は含めていません。

元の開発用シミュレータとは別フォルダーに整理しました。`app/` 内の各モジュールの相対参照を維持し、実行に必要な依存ライブラリだけを同梱しています。JSやURDFを編集できる形式のまま提供しており、難読化はしていません。

## 送付版で確認したこと

- Windows、Node.js 24.19.0でHTTP配信・両モデルの全キャッシュ配信・保存API・同時保存のファイル名分離を確認。
- 独立NumPy基準とブラウザ側の運動学を各モデルで比較し、両腕IK、首・腰、グリッパー、モデル切替・状態保持を検証。
- 同梱データによるGPU RGB-D、MID-360 Worker計測を実行。車両2車種とDracoデコーダの実読込を確認。
- ROS2連携コードのPython構文と、合成CDRパケットの整列・破損検出を検証。
- `tests/DELIVERY_MODEL_QA.json` は送付版でのブラウザ実行記録。`tests/baseline/` は整理前バージョンの検証履歴です。

日本語と空白を含む別フォルダーへZIPを展開し、起動・配信・保存を再確認しました。同梱STLから両モデルの37種類ずつのキャッシュを再生成し、74種類すべてで同梱キャッシュとのバイト一致を確認しています。再生成に元のZIPや開発フォルダーは使用していません。記録は `tests/PACKAGING_QA.json` です。

ZIP展開後のファイル検査は `node tools/verify.mjs`。細かな転送破損の確認用に `MANIFEST.json` とZIP全体の `.sha256` を添付します。

## 検証範囲の境界

Linux/macOSでの実機起動、受領先GPU、受領先ROS/VMとAiS-GNG-FVG本体の組合せは未検証です。受領先でREADMEの起動・検証手順を実行してください。センサは幾何・可視性モデルであり、実機の個体校正、露光や欠損率、ノイズを全面的に再現したものではありません。

AI連携用コードは同梱していますが、別プロジェクトのAiS-GNG-FVG本体・observer・独自ROSメッセージやVMイメージは含めていません。

## 素材の条件

依存ライブラリのライセンス本文と、3D素材の出典・加工内容を添付しています。CarConceptは配布元およびGLB内のCC BY 4.0表記を確認しています。Ferrariモデルの原作者ページは確認できず、Livox公式配布物の二次配布許諾を本整理作業で取得したものではありません。これらの公開・二次配布条件の判断は、ライブラリのMIT表記から推定せず、`THIRD_PARTY_NOTICES.md` / `docs/ASSET_SOURCES.md` の素材別情報を参照してください。

## 再パッケージ

ソース変更後、配布用ZIPとマニフェストを作り直す場合:

```text
python tools/package.py ../ToPoDualArmMax-Simulator-updated.zip
```

実行ログ・exports・秘密鍵等を除外するallowlistで作成します。追加モジュールを新規のトップレベルフォルダーに置いた場合は、`tools/package.py` の `TOP` を更新してください。
